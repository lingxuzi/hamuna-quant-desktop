## 角色定义



我是ETF/基金分析智能体，专注于中国公募基金市场（含跨境ETF），提供从品种筛选、深度分析到配置建议的全链路投资研究服务。我的分析基于公开市场数据和权威研究方法论，不提供具体买卖信号，而是提供分析框架和决策支持。



## 诚实边界



1. **信息截止**：本 Skill 的知识和方法论截止于2026年6月，不包含最新政策变化或市场数据。

2. **非投资建议**：所有分析仅为研究参考，不构成任何投资建议。投资决策需投资者自行承担风险。

3. **市场有效性假设**：部分套利策略基于理论推演，实际市场中套利空间可能因竞争而消失。

4. **数据依赖**：分析结论依赖公开数据的准确性和时效性，数据延迟或误差可能导致判断偏差。

5. **不可预测性**：市场短期走势不可预测，任何历史回测不代表未来表现。

6. **套利门槛**：ETF一二级市场套利通常需要百万级资金和程序化交易系统，散户参与受限。

7. **分级基金**：2021年后国内已基本停止分级基金新产品审批，存续产品逐步转型清盘，相关策略仅供参考。



## 一、ETF分类体系



### 1.1 大类资产分类



| 大类 | 说明 | 代表品种 | 风险等级 |

|------|------|----------|----------|

| **股票ETF** | 投资股票市场，跟踪股票指数 | 沪深300ETF、中证500ETF | 高 |

| **债券ETF** | 投资债券市场，跟踪债券指数 | 国债ETF、信用债ETF | 较低 |

| **商品ETF** | 跟踪大宗商品价格 | 黄金ETF、白银LOF | 中-高 |

| **货币ETF** | 投资短期货币工具 | 华宝添益、银华日利 | 极低 |

| **跨境ETF** | 跟踪境外市场指数 | 纳斯达克ETF、恒生科技ETF | 高 |



### 1.2 股票ETF细分类



| 类型 | 定义 | 特征 | 代表指数 |

|------|------|------|----------|

| **宽基ETF** | 覆盖广泛市场，不限制行业 | 分散度高、代表性强、适合底仓 | 沪深300、中证500、中证1000、创业板指、科创50、中证A500 |

| **行业ETF** | 跟踪特定行业指数 | 风险集中、适合行业轮动 | 银行ETF、证券ETF、半导体ETF、医药ETF、新能源ETF |

| **主题ETF** | 跟踪特定投资主题，可跨行业 | 介于宽基与行业之间 | AI主题、碳中和、军工、消费 |

| **策略ETF(Smart Beta)** | 采用非市值加权策略 | 因子驱动、风格明确 | 红利低波、质量、动量、等权、基本面加权 |



### 1.3 特殊类型



- **ETF联接基金**：场外基金，≥90%资产投资对应ETF，方便无股票账户投资者

- **LOF(Listed Open-ended Fund)**：既可场内交易又可场外申赎的开放式基金，采用现金申赎（区别于ETF实物申赎）

- **指数增强基金**：在跟踪指数基础上，通过主动/量化策略争取超额收益，关键看基金经理能力

- **分级基金**：将基金份额分为优先级(A)和进取级(B)，B份额自带杠杆。注：已逐步退出历史舞台



## 二、ETF选基方法论



### 2.1 三步选基法



```

第一步：明确投资需求 → 确定目标指数/资产类别

第二步：比较同指数ETF产品 → 筛选最优标的

第三步：执行配置 → 结合策略建仓

```



### 2.2 核心筛选指标



| 指标 | 重要性 | 说明 |

|------|--------|------|

| **基金规模** | ★★★★★ | 规模越大，流动性和折溢价控制越好。建议选择≥2亿元的ETF |

| **日均成交额** | ★★★★★ | 反映交易活跃度。日均成交<1000万的ETF谨慎参与 |

| **跟踪误差** | ★★★★☆ | 越小越好，通常<0.05%为优秀。年化跟踪误差=(NAV回报-指数回报)的标准差 |

| **管理费率** | ★★★☆☆ | ETF费率普遍较低(0.15%-0.5%/年)，同类型中选费率低的 |

| **折溢价率** | ★★★★☆ | 溢折率=(场内价格-IOPV)/IOPV，过高溢价意味着买入成本虚高 |

| **成立时间** | ★★★☆☆ | 运作时间越长，跟踪数据越丰富，建议>1年 |

| **基金公司** | ★★☆☆☆ | 大型基金公司在指数管理上更具经验优势 |



### 2.3 选基黄金原则



**原则一：规模与流动性优先**。ETF选基"两看"——看规模、看流动性。规模和日均成交额是最重要的两个指标，直接决定买卖成本和折溢价风险。



**原则二：费率差异不可忽视**。同指数ETF费率差可达0.3%/年以上，长期累积显著影响收益。



**原则三：跟踪误差越小越好**。完全复制型ETF跟踪误差优于抽样复制型，但管理费差异也影响跟踪误差。



**原则四：避免过高溢价买入**。跨境ETF和热门行业ETF易出现高溢价，溢价>2%时需极度警惕。



## 三、ETF套利策略



### 3.1 折溢价套利（一二级市场）



#### 核心原理

ETF同时存在两个价格：二级市场交易价格和一级市场净值(IOPV)，利用价差进行套利。



**IOPV(Indicative Optimized Portfolio Value)**：基金份额参考净值，每15秒更新一次，根据PCF清单中成分股实时价格估算。



#### 溢价套利（正向套利）

```

条件：场内价格 > IOPV，且价差 > 套利成本

流程：买入一篮子成分股 → 一级市场申购ETF → 二级市场卖出ETF

成本：约0.1%（佣金+冲击成本）

时间：T日完成（股票ETF支持T+0申赎）

```



#### 折价套利（反向套利）

```

条件：场内价格 < IOPV，且价差 > 套利成本

流程：二级市场买入ETF → 一级市场赎回获得一篮子股票 → 卖出股票

成本：约0.2%（含印花税）

时间：T日完成

```



#### 套利成本构成

- 交易佣金（万1-万3）

- 印花税（卖出时千1）

- 过户费（万0.2）

- 冲击成本（万1-万5，取决于资金量和流动性）



### 3.2 事件套利



利用ETF成分股的重大事件获取套利收益：



**停牌股套利**：

- 预期停牌股复牌大涨 → 买入含该股的ETF → 赎回获得一篮子股票 → 卖出其他股票 → 留存停牌股待复牌

- 预期停牌股复牌大跌 → 买入其他成分股 → 申购ETF → 卖出ETF（实现减持该停牌股）

- **前提**：停牌股的现金替代方式须为"允许现金替代"



**成分股调整套利**：

- 指数定期调整成分股时，调入/调出股票可能出现短期异常波动

- 关注调整公告日与生效日之间的价格偏差



### 3.3 期现套利



基于股指期货与现货ETF之间的价格偏差：



```

正向基差套利（期货价格 > 现货价格）：

  买入现货ETF + 卖出股指期货 → 等待基差收敛平仓



反向基差套利（期货价格 < 现货价格）：

  融券卖出现货ETF + 买入股指期货 → 等待基差收敛平仓

  （注：需融券支持）

```



**适用条件**：

- 基差异常偏离历史常态

- 市场极端情绪导致期现价差显著

- 需关注合约到期时间对套利窗口的影响



### 3.4 LOF套利



LOF采用现金申赎（区别于ETF实物申赎），套利门槛低，适合中小资金：



| 类型 | 条件 | 操作流程 | 周期 |

|------|------|----------|------|

| **溢价套利** | 场内价格 > 净值，价差 > 申购费+卖出佣金 | T日场内申购 → T+2日场内卖出 | T+2 |

| **折价套利** | 场内价格 < 净值，价差 > 买入佣金+赎回费 | T日场内买入 → T+1日场内赎回 | T+2 |



**关键要素**：

- 券商申购费率（一折0.15%最佳，原价1.5%基本无套利空间）

- 基金限购额度（限购越低，套利大军新增份额越有限，机会越好）

- 流动性（成交额越高越好，避免踩踏）

- 溢价水平（5%以上溢价才有吸引力）



### 3.5 套利风险清单



| 风险类型 | 说明 |

|----------|------|

| **执行风险** | 套利需要短时间内完成全流程，市场波动可能导致亏损 |

| **流动性风险** | 申购得到的ETF份额可能在二级市场无法及时卖出 |

| **赎回风险** | 现金替代的成分股实际买入成本与估算值可能偏离 |

| **跨市场风险** | 跨境ETF涉及汇率波动和T+N交收延迟 |

| **冲击成本** | 大额交易可能改变市场价格，侵蚀套利利润 |

| **政策风险** | 交易规则和费率可能调整，影响套利可行性 |



## 四、主动基金分析框架



### 4.1 分析维度



```

基金经理 → 投资体系 → 历史业绩 → 风险指标 → 基金公司 → 综合评级

```



### 4.2 基金经理评价



| 评价维度 | 具体内容 |

|----------|----------|

| **从业经历** | 学历背景、研究经历、管理基金年限。要求≥3年完整牛熊周期 |

| **管理规模** | 同时管理基金数量建议≤5只，过大则精力分散 |

| **投资风格** | 价值/成长/均衡、大盘/中小盘、换手率高低、集中度 |

| **风格稳定性** | 查看持仓风格漂移程度，长期坚持同一体系的基金经理更可靠 |

| **投研团队** | 基金公司投研实力（资产规模、产品线、金牛奖数量、人员稳定性） |



### 4.3 业绩分析指标



| 指标 | 公式/说明 | 判断标准 |

|------|-----------|----------|

| **绝对收益率** | 各阶段（1/3/5年）净值增长率 | 优于同类平均 |

| **相对收益率** | 相对沪深300和同类基金排名 | 四分位法：前25%优秀 |

| **超额收益(Alpha)** | Jensen's α = Rp - [Rf + β(Rm-Rf)] | α>0说明具备选股能力 |

| **夏普比率** | (Rp-Rf)/σp，单位风险超额收益 | 股票型/混合型>1为佳 |

| **最大回撤** | 区间内净值从峰值到谷值的最大跌幅 | 越小越好，>50%需谨慎 |

| **信息比率** | 超额收益/跟踪误差 | 衡量主动管理效率 |

| **换手率** | 年交易额/平均净资产 | 偏低(100%-200%)说明策略稳定 |

| **胜率/盈亏比** | 正收益月份数/总月份数 | 长期胜率>60%较优 |



### 4.4 基金评级体系



| 评级机构 | 评级方法 | 使用建议 |

|----------|----------|----------|

| **晨星(Morningstar)** | 基于风险调整后收益(MRAR)，关注波动率和下行风险 | 公认权威，长期4星以上为优质 |

| **招商证券** | 以Jensen α为核心，结合流动性评定 | 关注5年评级 |

| **银河证券** | 综合收益率、标准差、管理规模，1-5星 | 管理人评价体系较完善 |

| **上海证券** | 多维评级，考虑业绩持续性 | 可作交叉验证 |

| **济安金信** | 独特的五星评级体系 | 关注合规性评价 |



**评级使用原则**：

- 评级是**排名指标**，不是收益指标，仅代表过去表现

- 长期高星基金(4-5星持续3年+)综合表现更可靠

- 基金经理变动后，评级不会立即改变，存在滞后性

- 不同机构评级结果可能不同，建议综合参考



### 4.5 主动基金七大评价维度



1. **收益性**：各阶段收益表现，"好年份不错，坏年份不差"

2. **风险性**：最大回撤，控制亏损本金的能力

3. **业绩稳定性**：长期保持同类前列，而非大起大落

4. **风格稳定性**：投资风格不漂移，坚守能力圈

5. **规模适中**：过小有清盘风险，过大则"船大难掉头"

6. **基金公司实力**：老牌大厂投研平台更可靠

7. **基金经理稳定性**：连续执掌该基金，无频繁更换



## 五、定投策略



### 5.1 定投核心逻辑



定投通过"时间分散"平滑买入成本，利用**微笑曲线**原理：市场下跌→低价买入更多份额→市场回升→获利。



```

定投优势：

✓ 克服追涨杀跌的人性弱点

✓ 降低择时难度

✓ 适合没有大量一次性资金的投资者

✓ 复利效应长期累积

```



### 5.2 定投品种选择



| 类型 | 推荐品种 | 说明 |

|------|----------|------|

| **最佳定投标的** | 宽基ETF（沪深300、中证A500、中证500） | 波动适中，长期向上 |

| **策略ETF** | 红利低波ETF | 回撤较小，适合稳健定投 |

| **行业ETF** | 不建议作为单一定投标的 | 波动过大，可能长期底部震荡 |

| **不建议定投** | 货币基金、低波动债券基金 | 波动太小，定投无优势 |



### 5.3 定投方式对比



| 方式 | 说明 | 优点 | 缺点 |

|------|------|------|------|

| **定期定额** | 固定时间固定金额 | 操作简单，纪律性强 | 不考虑市场估值 |

| **均线定投** | 价格低于N日均线多买，高于均线少买 | 自动低位多投 | 判断依赖单一指标 |

| **估值定投** | 根据PE/PB历史分位调整金额 | 科学性强 | 需要估值数据 |

| **智能定投** | 综合多因子动态调整 | 最优化投入比例 | 实现复杂 |



### 5.4 定投关键参数



- **定投频率**：周定投/双周定投优于月定投（更精细平滑成本）

- **止盈策略**：目标收益率止盈（20%-30%）或最大回撤止盈（从高点回撤10%）

- **定投期限**：建议≥3年，穿越至少一个完整市场周期

- **持仓收益率区间**：-10%~-50%区间内坚持定投效果最佳；+10%~+50%区间"不操作"更优



## 六、FOF配置策略



### 6.1 资产配置策略



| 策略 | 说明 | 适用场景 |

|------|------|----------|

| **60/40策略** | 60%股票+40%债券，定期再平衡 | 经典配置，降低回撤 |

| **核心+卫星策略** | 60-80%宽基ETF核心+20-40%行业/主题ETF卫星 | 主流策略，兼顾稳健与进攻 |

| **全球多元化** | 跨资产类别+跨地区配置 | 分散单一市场风险 |

| **动态资产配置** | 根据经济周期动态调整股债比例 | 需要宏观判断能力 |

| **美林时钟轮动** | 复苏→股票，过热→商品，滞涨→现金，衰退→债券 | 理论框架，实际滞后明显 |



### 6.2 核心+卫星策略详解



```

核心仓位（60-80%）：

  - 目标：获取市场平均收益(Beta)

  - 品种：宽基ETF（沪深300ETF、中证500ETF）

  - 策略：买入并持有，低频调整



卫星仓位（20-40%）：

  - 目标：获取超额收益(Alpha)

  - 品种：行业ETF、策略ETF、跨境ETF、主动基金

  - 策略：主动管理，根据市场环境动态调仓

```



### 6.3 再平衡策略



| 方式 | 说明 | 频率建议 |

|------|------|----------|

| **时间触发** | 定期检查并调整至目标权重 | 半年或一年 |

| **阈值触发** | 偏离目标权重超过预设阈值(如±5%)时调整 | 灵活 |

| **再平衡成本** | 考虑交易费用和税收影响，过度再平衡得不偿失 | — |



### 6.4 目标日期/目标风险策略（FOF经典策略）



| 策略 | 核心逻辑 | 代表产品 |

|------|----------|----------|

| **目标日期(TDF)** | 随目标日期临近，自动降低股票比例，增加债券比例（下滑航道） | 养老目标日期FOF |

| **目标风险(TRF)** | 设定固定风险水平，维持恒定的股债配置比例 | 保守型/稳健型/积极型FOF |



## 七、回答工作流



```

Step 1: 需求分析

  ├── 投资目标（保值/增值/收入）

  ├── 风险承受能力（低/中/高）

  ├── 投资期限（短/中/长期）

  ├── 资金规模

  └── 特殊需求（定投/套利/配置）



Step 2: 品种筛选

  ├── 根据需求确定大类资产（股/债/商/跨境）

  ├── 同类ETF横向比较（规模/流动性/费率/跟踪误差）

Step 3: ETF/基金深度分析
```

## 八、风险知识库



### 8.1 ETF特有风险



| 风险 | 说明 | 应对 |

|------|------|------|

| **跟踪误差** | ETF实际收益与指数收益的偏离 | 选择跟踪误差小的产品 |

| **流动性风险** | 成交不活跃导致买卖价差大 | 日均成交额>1000万 |

| **折溢价风险** | 场内价格大幅偏离净值 | 避免追高溢价，关注溢折率 |

| **成分股风险** | 指数成分股集中或权重失衡 | 穿透成分股，看前十大权重 |

| **调仓风险** | 指数定期调整成分股产生交易成本 | 关注调整公告 |

| **汇率风险** | 跨境ETF受汇率波动影响 | 考虑汇率对冲 |



### 8.2 主动基金特有风险



| 风险 | 说明 |

|------|------|

| **基金经理变动** | 换将后基金可能面目全非 |

| **风格漂移** | 基金经理偏离其能力圈 |

| **规模膨胀** | 管理规模过大导致策略失效 |

| **集中度风险** | 重仓股高度集中，单一个股暴雷影响大 |

| **老鼠仓/利益输送** | 违规操作风险（虽属极少数） |



### 8.3 通用风险



- 系统性风险（宏观经济、政策变化）

- 流动性风险（极端行情下无法卖出）

- 利率风险（债券ETF）

- 信用风险（信用债ETF）

- 地缘政治风险（跨境ETF）

## 十、常用公式速查



```

折溢价率 = (场内价格 - IOPV) / IOPV × 100%



IOPV = ∑(成分股实时价格 × 权重) + 现金替代估值 + 其他资产净值



夏普比率 = (Rp - Rf) / σp



最大回撤 = (峰值净值 - 谷值净值) / 峰值净值 × 100%



Jensen's α = Rp - [Rf + βp × (Rm - Rf)]



LOF溢折率 = (场内价格 - 净值) / 净值 × 100%



分级基金整体溢价率 = [(A价格 + B价格) - 2×母基金净值] / (2×母基金净值) × 100%

```

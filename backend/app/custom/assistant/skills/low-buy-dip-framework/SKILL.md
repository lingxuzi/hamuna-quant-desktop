# 低吸战法智能体

## 定位

实战派中短线交易思维框架，专注于A股市场的回调低吸策略体系。为稳健型、厌恶追高的交易者提供系统化的低吸买入方法论，核心是"买在分歧，卖在一致"，在强势股回调时寻找确定性较高的入场机会。

---

## 核心认知模型

### 心智模型一：低吸的本质认知

**核心洞察**：低吸≠抄底，低吸是顺势而为的回调买入。

| 维度 | 低吸 | 抄底（错误认知） |
|------|------|-----------------|
| 趋势方向 | 上升趋势中的回调 | 下降趋势中的反弹博弈 |
| 风险特征 | 趋势保护，止损明确 | 无底洞，没有支撑 |
| 资金性质 | 主力洗盘后的承接 | 散户的赌博心态 |
| 成功率 | 高（有趋势+资金强度支撑） | 低（纯博弈） |

**决策原则**：
- 只吸上升趋势的强势股，不吸横盘、下跌的弱势股
- 必须有资金强度和辨识度，不碰无关注度的僵尸股
- 结合大盘节奏和板块热点，低吸才有效率

### 心智模型二：低吸的三重境界

```
分歧低吸 → 衰竭低吸 → 恐慌低吸
   ↓           ↓           ↓
主力博弈     技术形态     情绪极端
```

| 类型 | 触发条件 | 特征 | 风险等级 |
|------|---------|------|---------|
| 分歧低吸 | 主流人气股爆量后，该弱不弱有承接 | 有辨识度，主升趋势中 | ★★☆ |
| 衰竭低吸 | K线回踩重要位置，形态调整完成 | 极度缩量企稳，抛压衰竭 | ★★☆ |
| 恐慌低吸 | 大盘/情绪利空，连续被按一步杀到位 | 短时间杀跌过猛，换量承接 | ★★★ |

## 核心能力模块

### 能力一：回调低吸

**适用场景**：强势股上涨途中的正常回调

**识别标准**：
1. **缩量回档**：回调时成交量明显萎缩（至少低于前期上涨时的50%）
2. **回调幅度可控**：强势回调不破5日线，次强回调到10日线，弱势回调到20日线（此时已非低吸而是抄底）
3. **企稳形态**：出现十字星、长下影线、小阳线等止跌信号
4. **二次放量**：企稳后出现放量阳线确认反弹

**操作要点**：
```
强势回调（不破5日线）→ 当日或次日低吸
次强回调（到10日线企稳）→ 等重新站上5日线后低吸
弱势回调（到20日线）→ 观察方向，20日线向上才可介入
```

**经典形态**：
- **双针探底**：两次长下影线探底，第二次位置相近或略高
- **缩量回踩**：连续缩量回调后，量缩到地量水平企稳
- **平台回踩**：突破平台后回踩平台顶部不破

### 能力二：均线低吸

**核心均线体系**：

| 均线 | 别称 | 含义 | 低吸策略 |
|------|------|------|---------|
| 5日线 | 攻击线 | 短期攻击强度 | 超强势股回调首次触碰即可低吸 |
| 10日线 | 操盘线 | 短线操盘中枢 | 强势股回调到10日线企稳后低吸 |
| 20日线 | 生命线 | 中期趋势支撑 | 波段趋势股回调到20日线低吸 |
| 60日线 | 决策线 | 中长期趋势分水岭 | 大趋势确认后回踩低吸 |

**均线低吸决策树**：
```
股价回调到哪条均线？
├─ 5日线：多方非常强势，还在攻击状态 → 首次触碰可低吸
├─ 10日线：多方阻击空方，短线资金减少但仍掌控 → 等站上5日线后低吸
└─ 20日线：空方反击强，短期趋势向下 → 先观察方向再决策

触碰次数判断：
├─ 首次触碰某均线 → 可以低吸
├─ 第二次触碰 → 仍可低吸
└─ 第三次及以上 → 谨慎，可能支撑失效
```

**均线多头排列确认**：
- 标准多头：5日>10日>20日，全部拐头向上
- 黄金三角：5日线上穿10日线，再上穿20日线，10日线与20日线形成金叉
- 空中加油：MACD在零轴上方运行，不发生死叉

### 能力三：支撑位低吸

**支撑位识别体系**：

| 支撑类型 | 形成原因 | 可靠性 | 操作要点 |
|---------|---------|-------|---------|
| 均线支撑 | 市场平均成本线 | ★★★★ | 回调到均线附近企稳后介入 |
| 前期高点 | 突破后转化为支撑 | ★★★★ | 回踩前期高点不破确认支撑 |
| 密集成交区 | 大量换手位置 | ★★★☆ | 成交密集区上沿低吸 |
| 缺口支撑 | 跳空缺口的磁吸效应 | ★★★☆ | 缺口上沿企稳后介入 |
| 趋势线支撑 | 上升趋势线 | ★★★★ | 触碰上升趋势线不破 |
| 大阳线底 | 大阳线开盘价 | ★★★☆ | 回踩大阳线底部不破 |

**支撑位低吸验证三要素**：
1. **触碰不破**：股价触及支撑位后快速拉回
2. **量能萎缩**：回调到支撑位时成交量明显萎缩
3. **企稳信号**：出现止跌K线形态（长下影、十字星、阳包阴等）

### 能力四：恐慌低吸

**触发条件**：
- 大盘突发利空，个股被动跟随杀跌
- 板块情绪退潮，个股连续被按到跌停
- 短时间内杀跌过猛（如5%以上急跌）
- 股价远离分时均价线

**操作原则**：
```
恐慌低吸 ≠ 接飞刀

正确姿势：
├─ 一步杀到位：跌停或接近跌停后，出现换量承接
├─ 分时企稳：跳水后不再创新低，开始横盘震荡
├─ 量能变化：从缩量下跌到放量企稳
└─ 仓位控制：轻仓试探，不超过3成

错误姿势：
├─ 下跌途中无脑接盘
├─ 全仓赌反弹
└─ 没有止损预案
```

**恐慌低吸的仓位管理**：
- 首次恐慌低吸：不超过2成仓位
- 确认企稳后加仓：不超过总仓位的5成
- 止损必须预设：亏损5%无条件出局

### 能力五：分时低吸

**分时图核心要素**：

| 要素 | 含义 | 低吸信号 |
|------|------|---------|
| 分时均价线 | 当日平均成本线 | 价格跌破均线后快速收回，或均价线不跟随下跌 |
| 量能柱 | 每分钟成交量 | 下跌放量后缩量企稳，或底部出现大单承接 |
| 波浪结构 | 价格波动节奏 | 波底不破前低，底部逐渐抬高 |
| 大盘对比 | 个股与大盘强弱 | 大盘弱但个股抗跌，或个股被动跟跌 |

**分时低吸五法则**：

1. **冲高不封板先出再接**
   - 开盘10分钟内急拉但未封板，多为诱多
   - 先卖出底仓，等跳水时低位接回

2. **均价线不跟随法**
   - 价格下跌但均价线维持高位 → 低吸良机
   - 价格上涨但均价线不跟随 → 动能不足，高抛离场

3. **底部抬高结构**
   - 开盘后持续低位震荡，第一个低点未被跌破
   - 关注第三个低点位置，果断建仓底仓

4. **极限缩量杀跌**
   - 快速下跌超5%且缩量，价格远离均价线
   - 轻仓低吸，反弹回到均价线附近卖出做T

5. **大盘强弱对比**
   - 大盘强势但个股无动于衷 → 止盈离场
   - 大盘走弱但个股抗跌 → 主力逆势吸筹，可低吸

### 能力六：低吸选股

**选股漏斗模型**：

```
第一层：趋势筛选
├─ 均线多头排列（5>10>20）
├─ 股价在20日线之上
└─ MACD零轴上方运行

第二层：资金筛选
├─ 近期有放量上涨（至少30%以上涨幅）
├─ 换手率活跃（3%-20%区间）
└─ 有板块辨识度或龙头属性

第三层：回调筛选
├─ 缩量回调到关键均线
├─ 回调幅度不超过前期涨幅的50%
└─ 出现企稳K线形态

第四层：时机筛选
├─ 回调后第3-5天介入
├─ 大盘处于震荡或上升阶段
└─ 板块热点未退潮
```

**低吸选股公式（通达信参考）**：
```
{均线多头排列}
MA5>MA10 AND MA10>MA20 AND MA5>REF(MA5,1);

{缩量回调}
VOL<REF(VOL,1)*0.5 AND CLOSE>MA10;

{企稳形态}
(CLOSE-LOW)/(HIGH-LOW)>0.6 AND VOL>REF(VOL,1)*1.2;
```

## 完整交易流程

### 趋势判断（第一步）

**判断维度**：
1. **大盘趋势**：指数处于上升、震荡还是下跌阶段
2. **板块趋势**：热点板块是否持续，龙头股走势
3. **个股趋势**：均线排列、MACD状态、成交量变化

**趋势确认清单**：
- [ ] 20日线上方运行
- [ ] 5日、10日、20日线多头排列
- [ ] MACD零轴上方或金叉状态
- [ ] 近期有放量上涨记录

### 低吸位识别（第二步）

**低吸位优先级**：

| 优先级 | 位置类型 | 成功率 | 收益预期 |
|-------|---------|-------|---------|
| 1 | 5日线首次回调 | 高 | 稳健 |
| 2 | 10日线企稳 | 较高 | 中等 |
| 3 | 前期高点回踩 | 高 | 较好 |
| 4 | 缺口上沿 | 中等 | 较好 |
| 5 | 20日线支撑 | 中等 | 波段 |

### 入场确认（第三步）

**入场信号组合**：

必须满足（全部）：
- [ ] 回调到关键位置不破
- [ ] 成交量明显萎缩
- [ ] 出现企稳K线形态

加分项（越多越好）：
- [ ] 板块龙头或辨识度股
- [ ] 大盘环境配合
- [ ] MACD未死叉或即将金叉
- [ ] 分时图出现承接信号

### 止损设置（第四步）

**止损原则**：

| 止损类型 | 设置方法 | 适用场景 |
|---------|---------|---------|
| 绝对止损 | 亏损5%-8%无条件止损 | 所有低吸操作 |
| 支撑止损 | 跌破关键支撑位止损 | 均线、前高等 |
| 形态止损 | 跌破企稳形态最低价 | 双针探底等形态 |
| 时间止损 | 买入后3天不涨则止损 | 短线操作 |

**止损铁律**：
```
支撑破位必出局，不抱幻想不留恋
止损条件进场时就定好，盘中严格执行
亏损不加仓，越亏越割肉
```

### 目标管理（第五步）

**止盈策略**：

| 策略类型 | 操作方法 | 适用场景 |
|---------|---------|---------|
| 固定止盈 | 盈利10%-20%分批止盈 | 短线操作 |
| 移动止盈 | 盈利后移动止损线，锁定利润 | 波段操作 |
| 压力位止盈 | 遇到明显压力位获利了结 | 技术派 |
| 分批止盈 | 盈利后先卖一半，另一半博更高 | 稳健派 |

**止盈心态**：
- 不追求卖在最高点，只赚自己认知范围内的钱
- 贪婪是亏损的开始，学会满足
- 卖飞好过被套，保住本金最重要

## 风险控制体系

### 仓位管理

| 大盘环境 | 单次低吸仓位 | 总仓位上限 |
|---------|-------------|-----------|
| 强势上升 | 30%-50% | 80% |
| 震荡市 | 20%-30% | 60% |
| 弱势震荡 | 10%-20% | 40% |
| 下跌趋势 | 不操作 | 空仓 |

### 禁忌清单

**绝对不做**：
- ❌ 下降趋势中低吸（抄底）
- ❌ 横盘震荡股低吸（无趋势）
- ❌ 无成交量、无关注度的僵尸股低吸
- ❌ 连续下跌不止的低吸（接飞刀）
- ❌ 全仓单一标的低吸
- ❌ 亏损后加仓摊成本

**必须做到**：
- ✅ 进场前确定止损位置
- ✅ 执行止损纪律，不留幻想
- ✅ 每次操作复盘，记录得失
- ✅ 保持交易连续性，不中断记录

## 使用边界

### 适用范围
- A股市场
- 中短线交易（持股1-15天）
- 有一定交易基础者
- 稳健型、厌恶追高的交易风格

- 新手完全不懂技术分析
- 长线价值投资
- 港股、美股、期货等
- 高频交易、量化交易

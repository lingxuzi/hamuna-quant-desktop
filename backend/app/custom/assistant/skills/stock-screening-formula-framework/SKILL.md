## 一、选股公式编写语法

### 1.1 通达信公式语法

#### 基础行情函数
```
CLOSE / C      收盘价
OPEN / O       开盘价
HIGH / H       最高价
LOW / L        最低价
VOL / V        成交量（手）
AMOUNT         成交金额（元）
```

#### 引用函数
```
REF(X, N)           引用N周期前的X值
                    例：REF(C, 1) 表示昨日收盘价

HHV(X, N)           N周期内X的最高值
                    例：HHV(H, 20) 表示20日最高价

LLV(X, N)           N周期内X的最低值
                    例：LLV(L, 20) 表示20日最低价

MA(X, N)            X的N日简单移动平均
                    例：MA(C, 5) 表示5日均线

EMA(X, N)           X的N日指数移动平均
                    例：EMA(C, 12) 表示12日指数均线

SMA(X, N, M)        X的N日加权移动平均，权重M
```

#### 逻辑函数
```
CROSS(A, B)         A上穿B（金叉）
                    例：CROSS(MA(C,5), MA(C,10)) 表示5日线上穿10日线

IF(条件, 值1, 值2)   条件判断
                    例：IF(C>O, 1, 0) 阳线返回1，否则返回0

AND / &&            逻辑与（两个条件同时满足）
OR / ||             逻辑或（任一条件满足）
NOT                 逻辑非
```

#### 统计函数
```
COUNT(条件, N)       统计N周期内条件满足的次数
                    例：COUNT(C>O, 5) 统计5日内阳线数量

SUM(X, N)           X的N周期求和
                    例：SUM(V, 5) 5日成交量之和

MAX(A, B)           取较大值
MIN(A, B)           取较小值

ABS(X)              绝对值
SQRT(X)             平方根
```

#### 时间函数
```
BARSLAST(条件)       上一次条件成立到当前的周期数
                    例：BARSLAST(CROSS(MA(C,5), MA(C,10))) 上次金叉距今天数

BARSSINCE(条件)      第一次条件成立到当前的周期数
```

#### 财务函数
```
FINANCE(1)          总股本（万股）
FINANCE(7)          流通股本（万股）
FINANCE(40)         总市值
DYNAINFO(4)         今开
DYNAINFO(7)         现价
DYNAINFO(17)        量比
```

### 1.2 同花顺公式语法

同花顺支持自然语言选股（问财）和公式选股两种方式：

#### 问财自然语言示例
```
"MACD金叉且均线多头排列"
"市盈率小于20且市净率小于2的股票"
"近三年净利润增长率均大于20%的股票"
"营收连续三年增长且资产负债率小于50%"
```

#### 公式语法（与通达信基本兼容）
```
MA5:=MA(C, 5);
MA10:=MA(C, 10);
CROSS(MA5, MA10);    // 5日金叉10日
```

## 二、经典选股公式库

### 2.1 均线类公式

#### 均线金叉选股（5日上穿10日）
```
MA5:=MA(C, 5);
MA10:=MA(C, 10);
金叉:CROSS(MA5, MA10);
```

#### 均线多头排列
```
MA5:=MA(C, 5);
MA10:=MA(C, 10);
MA20:=MA(C, 20);
MA60:=MA(C, 60);
多头:MA5>MA10 AND MA10>MA20 AND MA20>MA60;
```

#### 均线粘合突破
```
MA30:=MA(C, 30);
MA60:=MA(C, 60);
MA90:=MA(C, 90);
MA120:=MA(C, 120);
AA:=MAX(MA120, MAX(MA30, MAX(MA60, MA90)));
BB:=MIN(MA120, MIN(MA30, MIN(MA60, MA90)));
粘合度:=(AA-BB)/BB*100<5;  {四条均线粘合，幅度小于5%}
突破:C>AA AND 粘合度;
```

#### 股价站上多条均线
```
MA5:=MA(C, 5);
MA10:=MA(C, 10);
MA20:=MA(C, 20);
站上:C>MA5 AND C>MA10 AND C>MA20;
```

### 2.2 量价类公式

#### 放量选股（成交量倍量）
```
放量:V/REF(V, 1)>2;  {今日成交量是昨日的2倍以上}
```

#### 缩量选股
```
缩量:V/MA(V, 10)<0.5;  {成交量低于10日均量的一半}
```

#### 放量大涨
```
大涨:C/REF(C, 1)>1.06;  {涨幅大于6%}
放量:V/REF(V, 1)>2;     {成交量翻倍}
放量大涨:大涨 AND 放量;
```

#### 量价齐升
```
量增:V>REF(V, 1);
价升:C>REF(C, 1);
量价齐升:量增 AND 价升;
```

#### 换手率筛选（3%-10%）
```
换手率:V/CAPITAL*100>3 AND V/CAPITAL*100<10;
```

### 2.3 MACD类公式

#### MACD金叉选股
```
DIF:=EMA(C, 12)-EMA(C, 26);
DEA:=EMA(DIF, 9);
金叉:CROSS(DIF, DEA);
```

#### MACD零轴上金叉（更强信号）
```
DIF:=EMA(C, 12)-EMA(C, 26);
DEA:=EMA(DIF, 9);
零上金叉:DIF>0 AND DEA>0 AND CROSS(DIF, DEA);
```

#### MACD金叉放量
```
DIF:=EMA(C, 12)-EMA(C, 26);
DEA:=EMA(DIF, 9);
MACD:=2*(DIF-DEA);
金叉:=CROSS(DIF, DEA);
放量:=V>REF(V, 1)*1.5;
金叉放量:金叉 AND 放量;
```

#### MACD底背离
```
DIFF:=EMA(C, 12)-EMA(C, 26);
DEA:=EMA(DIFF, 9);
A1:=BARSLAST(REF(CROSS(DIFF, DEA), 1));
底背离:REF(C, A1+1)>C AND REF(DIFF, A1+1)<DIFF AND CROSS(DIFF, DEA);
```

### 2.4 KDJ类公式

#### KDJ金叉选股
```
RSV:=(C-LLV(L, 9))/(HHV(H, 9)-LLV(L, 9))*100;
K:=SMA(RSV, 3, 1);
D:=SMA(K, 3, 1);
金叉:CROSS(K, D);
```

#### KDJ低位金叉（超卖区）
```
RSV:=(C-LLV(L, 9))/(HHV(H, 9)-LLV(L, 9))*100;
K:=SMA(RSV, 3, 1);
D:=SMA(K, 3, 1);
低位金叉:K<20 AND CROSS(K, D);  {K值小于20的金叉}
```

#### KDJ底背离
```
RSV:=(C-LLV(L, 9))/(HHV(H, 9)-LLV(L, 9))*100;
K:=SMA(RSV, 3, 1);
D:=SMA(K, 3, 1);
A2:=BARSLAST(REF(CROSS(K, D), 1));
底背离:REF(C, A2+1)>C AND REF(K, A2+1)<K AND CROSS(K, D);
```

### 2.5 RSI类公式

#### RSI金叉选股
```
RSI1:=SMA(MAX(C-REF(C, 1), 0), 6, 1)/SMA(ABS(C-REF(C, 1)), 6, 1)*100;
RSI2:=SMA(MAX(C-REF(C, 1), 0), 12, 1)/SMA(ABS(C-REF(C, 1)), 12, 1)*100;
金叉:CROSS(RSI1, RSI2);
```

#### RSI超卖选股（RSI<30）
```
RSI1:=SMA(MAX(C-REF(C, 1), 0), 6, 1)/SMA(ABS(C-REF(C, 1)), 6, 1)*100;
超卖:RSI1<30;
```

#### RSI底背离
```
RSI1:=SMA(MAX(C-REF(C, 1), 0), 6, 1)/SMA(ABS(C-REF(C, 1)), 6, 1)*100;
RSI2:=SMA(MAX(C-REF(C, 1), 0), 12, 1)/SMA(ABS(C-REF(C, 1)), 12, 1)*100;
A3:=BARSLAST(REF(CROSS(RSI1, RSI2), 1));
底背离:REF(C, A3+1)>C AND REF(RSI1, A3+1)<RSI1 AND CROSS(RSI1, RSI2);
```

### 2.6 综合类公式（多指标共振）

#### 三金叉选股（均线+均量+MACD）
```
MA5:=MA(C, 5);
MA10:=MA(C, 10);
均线金叉:=CROSS(MA5, MA10);

MV5:=MA(V, 5);
MV10:=MA(V, 10);
均量金叉:=CROSS(MV5, MV10);

DIF:=EMA(C, 12)-EMA(C, 26);
DEA:=EMA(DIF, 9);
MACD金叉:=CROSS(DIF, DEA);

三金叉:均线金叉 AND 均量金叉 AND MACD金叉;
```

#### 三底背离选股（MACD+KDJ+RSI）
```
{MACD底背离}
DIFF:=EMA(C, 12)-EMA(C, 26);
DEA:=EMA(DIFF, 9);
A1:=BARSLAST(REF(CROSS(DIFF, DEA), 1));
B1:=REF(C, A1+1)>C AND REF(DIFF, A1+1)<DIFF AND CROSS(DIFF, DEA);

{KDJ底背离}
RSV:=(C-LLV(L, 9))/(HHV(H, 9)-LLV(L, 9))*100;
K:=SMA(RSV, 3, 1);
D:=SMA(K, 3, 1);
A2:=BARSLAST(REF(CROSS(K, D), 1));
B2:=REF(C, A2+1)>C AND REF(K, A2+1)<K AND CROSS(K, D);

{RSI底背离}
RSI1:=SMA(MAX(C-REF(C, 1), 0), 6, 1)/SMA(ABS(C-REF(C, 1)), 6, 1)*100;
RSI2:=SMA(MAX(C-REF(C, 1), 0), 12, 1)/SMA(ABS(C-REF(C, 1)), 12, 1)*100;
A3:=BARSLAST(REF(CROSS(RSI1, RSI2), 1));
B3:=REF(C, A3+1)>C AND REF(RSI1, A3+1)<RSI1 AND CROSS(RSI1, RSI2);

底背离:B1>0 OR B2>0 OR B3>0;
```

### 2.7 涨停板类公式

#### 涨停板识别
```
涨停:C/REF(C, 1)>=1.095 AND C=H;  {涨幅>=9.5%且以最高价收盘}
```

#### N日内有涨停
```
涨停:=C/REF(C, 1)>=1.095 AND C=H;
N日涨停:EXIST(涨停, 10);  {10日内有涨停}
```

#### 涨停回调选股
```
涨停:=C/REF(C, 1)>=1.095 AND C=H;
涨停日:=BARSLAST(涨停);
回调:=涨停日<=5 AND C<REF(C, 涨停日)*0.95 AND C>REF(C, 涨停日)*0.85;
缩量:=V<REF(V, 涨停日)*0.5;
涨停回调:涨停日>0 AND 回调 AND 缩量;
```

#### 倍量涨停
```
涨停:=C/REF(C, 1)>=1.095 AND C=H;
倍量:=V>REF(V, 1)*2;
倍量涨停:涨停 AND 倍量;
```

### 2.8 突破类公式

#### 创新高选股
```
创新高:C=HHV(C, 60);  {创60日新高}
```

#### 突破平台
```
平台高点:=REF(HHV(H, 20), 1);
突破:C>平台高点 AND V>MA(V, 5)*1.5;  {放量突破20日高点}
```

#### 箱体突破
```
箱顶:=MA(REF(HHV(C, 30), 1), 2);
箱底:=MA(REF(LLV(C, 30), 1), 2);
突破:C>箱顶 AND V>REF(V, 1)*1.5;
```

#### 放量突破60日线
```
突破:C>MA(C, 60) AND CROSS(C, MA(C, 60)) AND V>REF(V, 1)*1.5;
```

### 2.9 筹码类公式

#### 筹码集中度选股
```
A1:=COST(85);  {85%筹码成本}
A2:=COST(15);  {15%筹码成本}
A3:=A1-A2;
A4:=(A1+A2)/2;
集中度:=A3/A4*100;
筹码集中:集中度<10;  {集中度小于10%}
```

#### 低位单峰密集
```
CM90:=COST(95)-COST(5);  {90%筹码区间宽度}
集中度:=CM90/C*100;
低位:=COST(50)<LLV(L, 200)*1.2;  {筹码峰在低位}
单峰密集:集中度<5 AND 低位;
```

### 2.10 其他实用公式

#### 阳包阴
```
阳包阴:C>O AND C>REF(O, 1) AND O<REF(C, 1) AND V>REF(V, 1)*1.5;
```

#### 连续N日上涨

```
连涨:COUNT(C>REF(C, 1), 5)=5;  {连续5日上涨}
```

```
大阳:(C-REF(C, 1))/REF(C, 1)>0.05;  {涨幅大于5%}
```

#### 跳空高开

```
高开:O>REF(H, 1);  {开盘价高于昨日最高价}
```

```
温和放量:V>REF(V, 1) AND V<REF(V, 1)*2 AND V>MA(V, 5);
```

## 三、选股策略设计框架

### 3.1 策略设计五要素

#### 1. 入场条件
- 技术信号：金叉、突破、背离等
- 量能确认：放量、缩量、换手率等
- 形态确认：W底、头肩底、圆弧底等

#### 2. 过滤条件
- 趋势过滤：均线方向、MACD方向
- 基本面过滤：市盈率、市净率、ROE等
- 市场环境：大盘趋势、板块热度

#### 3. 止损条件
- 固定止损：跌破买入价的N%
- 技术止损：跌破关键均线或支撑位
- 时间止损：N日内未盈利则退出

#### 4. 止盈条件
- 固定止盈：达到目标收益
- 移动止盈：跟踪止损，保护利润
- 技术止盈：出现卖出信号

#### 5. 仓位管理
- 单只股票仓位上限
- 分批买入/卖出策略
- 总仓位控制

### 3.2 策略示例：均线金叉+量价配合

```
{策略思路：5日均线金叉10日均线，同时成交量放大}

{入场条件}
MA5:=MA(C, 5);
MA10:=MA(C, 10);
金叉:=CROSS(MA5, MA10);
放量:=V>REF(V, 1)*1.5;
入场:金叉 AND 放量;

{过滤条件}
趋势向上:=MA10>REF(MA10, 1);  {10日线向上}
过滤:趋势向上;

{完整选股}
选股:入场 AND 过滤;
```

## 四、回测与优化

### 4.1 回测方法

#### 通达信回测步骤
1. 打开公式管理器（Ctrl+F）
2. 创建选股公式
3. 使用"条件选股"功能（Ctrl+T）
4. 选择"历史阶段选股"
5. 设置时间段、初始资金等参数
6. 执行回测并分析结果

#### 回测关键指标
- **总收益率**：整体盈利情况
- **年化收益率**：折算年化收益
- **最大回撤**：最大亏损幅度
- **胜率**：盈利交易占比
- **盈亏比**：平均盈利/平均亏损
- **夏普比率**：风险调整后收益

### 4.2 常见陷阱识别

#### 过拟合陷阱
**表现：**
- 回测曲线完美，实盘亏损
- 参数极度敏感（20日均线有效，19日无效）
- 参数过于精确（如均线周期13.87天）

**规避方法：**
- 样本外测试：用70%数据训练，30%数据验证
- 参数鲁棒性测试：参数微调后策略仍应有效
- 简化规则：参数不超过3个，规则能一句话说清

#### 未来函数陷阱
**表现：**
- 使用了当时无法获得的数据
- 如用收盘价信号假设能以收盘价成交

**规避方法：**
- 信号用今日，执行用次日开盘价
- 财报数据用发布后一天的数据
- 避免使用当日最高最低价做决策

#### 幸存者偏差
**表现：**
- 只测试现有股票，忽略已退市股票
- 回测结果虚高

**规避方法：**
- 使用包含退市股票的全市场数据
- 或至少测试足够长的历史周期

#### 曲线拟合
**表现：**
- 通过不断调整参数"雕刻"出完美曲线
- 添加过多过滤条件
- 发现"每月15日买入"等无意义规律

**规避方法：**
- 限制参数数量
- 规则要有经济学逻辑支撑
- 多市场验证（A股、港股、美股）

### 4.3 优化原则

#### 有效优化
1. **参数优化**：测试不同参数组合，选择稳健区间
2. **条件优化**：增加有效过滤条件，减少假信号
3. **风险优化**：完善止损止盈规则

#### 无效优化（应避免）
1. 为拟合历史而添加复杂规则
2. 追求过高的回测收益率
3. 使用过多的参数和条件

#### 优化检验清单
- [ ] 参数是否在合理范围内？
- [ ] 规则是否能用简单逻辑解释？
- [ ] 样本外测试是否有效？
- [ ] 不同市场环境下是否稳健？
- [ ] 是否考虑了交易成本和滑点？

## 五、诚实边界

### 5.1 选股公式的局限

#### 历史拟合风险
- 选股公式基于历史数据，未来市场可能完全不同
- 没有任何公式能保证持续盈利
- 过去有效的策略可能在未来失效

#### 市场变化风险
- 市场结构变化（注册制、T+0等）
- 投资者行为变化
- 政策环境变化
- 技术进步导致的市场效率提升

#### 过度优化风险
- 追求完美回测曲线往往导致实盘失败
- 参数越多，过拟合风险越高
- 复杂策略往往不如简单策略稳健

### 5.2 技术分析的局限

#### 滞后性
- 所有技术指标都是基于历史数据计算
- 信号出现时往往已有一定涨幅/跌幅

#### 骗线
- 主力可能制造假突破、假金叉
- 技术形态可能被操纵

#### 忽视基本面
- 纯技术分析忽略公司质量
- 可能选出"垃圾股"的技术买点

### 5.3 正确使用建议

#### 公式只是工具
- 选股公式是辅助决策工具，不是圣杯
- 应结合基本面分析、市场环境综合判断
- 保持独立思考，不盲从公式信号

#### 风险控制至上

# 新闻舆情分析框架 Skill



> 版本: 1.0 | 信息截止: 2026-06-12 | 作者: 女娲蒸馏



## 核心理念



新闻舆情不是"看新闻炒股"——它是系统化的信息分类、信号识别、影响评估和情绪判断框架。一条新闻的价值不在于它说了什么，在于它对市场预期改变了什么。



---



## 一、新闻分类体系



### 1.1 四级分类



| 类别 | 定义 | 典型示例 | 影响范围 |

|------|------|----------|----------|

| **政策新闻** | 政府及监管机构发布的法规、规划、调控措施 | 央行降息/加息、证监会新规、行业补贴政策、财政预算 | 全市场/行业级 |

| **行业新闻** | 行业层面的技术突破、供需变化、竞争格局演变 | 光电计算芯片突破、猪病大规模爆发、芯片产能过剩 | 行业/板块级 |

| **公司新闻** | 单个上市公司的业绩、并购、诉讼、管理层变动 | 业绩超预期、重大合同、被立案调查、高管辞职 | 个股级 |

| **国际新闻** | 地缘政治、全球宏观经济、国际条约与冲突 | 中美贸易谈判进展、美联储决议、俄乌局势升级 | 全市场/跨境板块 |



### 1.2 分类判断规则



1. **优先看来源**：政策新闻→国务院/央行/证监会官网；行业→行业协会/权威研报；公司→交易所公告；国际→外交部/路透社

2. **再看影响层级**：一条新闻如果从宏观传导到行业再到个股，归类取最高层级（如央行降息既是政策新闻也影响行业和个股，归为"政策新闻"）

3. **避免误分类**：公司级利好被媒体渲染为行业利好时，需冷静判断——该利好是否真的对整个行业有效？

## 二、舆情信号识别：利好/利空/中性



### 2.1 信号判断框架



```

新闻内容 → 是否改变市场预期？

  ├── 改变预期向上 → 利好信号

  ├── 改变预期向下 → 利空信号

  ├── 未改变预期或方向不明 → 中性信号

```



### 2.2 利好信号清单



| 信号维度 | 具体表现 |

|----------|----------|

| **政策利好** | 降息降准、减税降费、行业补贴、放宽准入、鼓励创新 |

| **行业利好** | 技术突破、需求激增、成本下降、竞争格局改善 |

| **公司利好** | 业绩超预期、重大订单、并购优质资产、回购增持 |

| **国际利好** | 贸易协议达成、地缘冲突缓和、全球需求回暖 |



### 2.3 利空信号清单



| 信号维度 | 具体表现 |

|----------|----------|

| **政策利空** | 加息提准、行业整顿、收紧监管、限制准入 |

| **行业利空** | 产能过剩、需求萎缩、成本飙升、恶性竞争 |

| **公司利空** | 业绩暴雷、财务造假、重大诉讼、减持清仓 |

| **国际利空** | 贸易摩擦升级、制裁扩大、地缘冲突恶化 |



### 2.4 关键认知：利好利空的非对称性



**研究依据**: Dangl & Salbrechter (2022) 对1996-2020年4000万条标普500成分股新闻的统计分析发现：



1. **同向强化 = 过度反应**：当天股价涨 + 收盘后利好 → 次日高开低走（过度反应大概率逆转）

2. **反向冲突 = 反应不足**：当天股价涨 + 收盘后利空 → 次日低开高走（反应不足，利空消化慢）

3. **无消息时开盘方向几乎无法预测**



**实战启示**：

- 利好出尽未必是利空，要看当日走势是否已经提前反应

- 利空出尽未必是利好，要看市场是否已充分定价

- **判断核心不是消息本身，而是消息与已有预期的差值**



### 2.5 利好/利空的分级



| 级别 | 定义 | 判断标准 | 对股价的典型影响 |

|------|------|----------|------------------|

| **重大** | 对核心预期产生根本性改变 | 政策级/行业级结构性变化 | ±5%以上，持续性 |

| **中等** | 对局部预期有明确改变 | 行业/公司级有实质内容 | ±2-5%，短期到中期 |

| **轻微** | 对预期影响有限 | 绪面/短期扰动 | ±1-2%，一日行情 |

| **噪音** | 看似相关实则无关 | 无实质内容，标题党 | 无实质影响 |

## 三、新闻对股价的影响机制



### 3.1 三层传导模型



```

新闻发布

  → Layer 1: 预期修正（投资者更新对公司/行业/宏观的预期）

    → Layer 2: 情绪传导（预期修正引发集体情绪——乐观/悲观/恐慌）

      → Layer 3: 行为执行（情绪转化为交易行为——买入/卖出/观望）

        → 股价变动

```



### 3.2 影响强度因子



| 因子 | 权重方向 | 说明 |

|------|----------|------|

| **意外度** | 越意外越强 | 与市场预期的偏差越大，影响越强 |

| **权威性** | 越权威越强 | 央行公告 > 券商研报 > 财经博主 |

| **传播速度** | 越快越强 | 官方渠道即时传播 > 社媒延迟传播 |

| **持续性** | 越持久越强 | 政策结构性变化 > 一次性事件 |

| **可验证性** | 越可验证越强 | 有数据支撑 > 纯定性描述 |



### 3.3 常见影响偏差



| 偏差类型 | 表现 | 原因 |

|----------|------|------|

| **过度反应** | 利好后高开低走，利空后低开高走 | 短期情绪驱动，与当日走势同向强化 |

| **反应不足** | 利好后低开高走，利空后高开低走 | 市场消化慢，与当日走势反向冲突 |

| **提前定价** | 利好公布时股价不变甚至下跌 | 市场已提前预期并反映 |

| **延迟反应** | 利空公布后几日才开始下跌 | 信息传递链长，散户后知后觉 |

## 四、热点题材跟踪方法



### 4.1 题材识别框架



```

舆情热点信号来源：

  ├── 官方政策文件（国务院公报、部委通知）

  ├── 交易所公告（并购、IPO、退市风险）

  ├── 行业研报（券商集体覆盖 = 风口信号）

  ├── 财经媒体聚焦（多家权威媒体同日报道同一主题）

  ├── 社媒热度（微博热搜、股吧讨论量突增）

  └── 题材龙头股异动（龙头率先涨停 = 题材启动信号）

```



### 4.2 题材生命周期



| 阶段 | 特征 | 操作策略 |

|------|------|----------|

| **萌芽期** | 少数人关注，龙头开始异动 | 信息收集，跟踪龙头 |

| **爆发期** | 媒体大量报道，板块集体拉升 | 确认龙头，谨慎跟进 |

| **扩散期** | 边缘股补涨，研报密集出台 | 注意分化，只持有龙头 |

| **衰退期** | 题材轮动到新热点，龙头滞涨 | 及时撤退，不恋战 |



### 4.3 题材跟踪注意事项



1. **区分真题材与伪题材**：真题材有政策/技术/需求支撑；伪题材只有概念包装和故事

2. **警惕概念绑架**：某公司仅完成DeepSeek本地化部署就被归入"DeepSeek概念股"，实则业务关联极弱

3. **题材轮动节奏**：A股题材轮动通常3-7天一个周期，爆发期最长持续不超过2周

4. **龙头的判断标准**：最先涨停、市值适中、基本面有实质关联、封板坚决

## 五、舆情情绪判断



### 5.1 绪维度模型



| 维度 | 定义 | 观察指标 |

|------|------|----------|

| **方向** | 看多/看空 | 股吧讨论偏向、分析师评级比例 |

| **强度** | 激烈程度 | 讨论量增速、情绪词频率、极端表达占比 |

| **一致性** | 多空分歧度 | 多空比、观点分散度、是否形成共识 |

| **持续性** | 情绪延续力 | 情绪是否逐日衰减、是否有新信息接力 |



### 5.2 情绪信号解读



| 信号 | 含义 | 实战意义 |

|------|------|----------|

| **极度乐观 + 高一致性** | 市场过度一致看多 | ⚠️ 可能是顶部信号，反向思考 |

| **极度悲观 + 高一致性** | 市场过度一致看空 | ⚠️ 可能是底部信号，反向思考 |

| **分歧加大 + 强度上升** | 多空激烈博弈 | 方向未定，但波动加大，需等确认 |

| **情绪温和衰减** | 市场逐步冷静 | 波动减小，回归基本面定价 |



### 5.3 NLP情感分析技术参考



学术研究表明NLP情感分析可用于辅助市场判断，但需注意：

- **Tetlock (2007)**: 证明媒体悲观词汇量与市场下行存在统计关联

- **Dangl & Salbrechter (2022)**: 量化了利好利空的非对称反应模式

- **Springer (2021)**: 发现单纯加入情感分析对股价预测的改进有限，需结合更复杂的模型结构



**实操建议**：NLP是辅助工具而非决策工具——可用于快速筛选海量新闻的方向和强度，但最终判断仍需人工结合基本面。

## 六、假新闻/谣言识别



### 6.1 五步识别法



```

Step 1: 查来源

  → 是否来自证监会指定信息披露平台？

  → 是否来自权威财经媒体（财新、第一财经、证券时报）？

  → 来源不明 → 🚨 立即拉响警报



Step 2: 查动机

  → 发布者是否有操纵股价动机？

  → 是否引导你进VIP群、付费荐股、私域交易？

  → 煽动情绪词汇（"全仓跟上""不要外传""名额有限"）→ 🚨 高危



Step 3: 查内容

  → 是否有具体数据、时间、人物支撑？

  → 是否与公司基本面和行业常识相符？

  → AI生成截图、PS"内部文件" → 🚨 常见造假手法



Step 4: 交叉验证

  → 公司官方公告是否确认？

  → 多家权威媒体是否独立报道？

  → 只有一个来源、其他渠道无佐证 → 🚨 孤证不立



Step 5: 观市场

  → 股价是否异常波动但基本面无变化？

  → 是否有资金先建仓再配合谣言出货的迹象？

  → 异动+谣言+无实质 = 🚨 操纵嫌疑

```



### 6.2 2024-2026典型谣言模式



| 模式 | 操作手法 | 案例 |

|------|----------|------|

| **AI生成谣言** | 引导AI大模型给出错误关联，截图传播 | 多家公司被虚假关联DeepSeek概念 |

| **小作文** | 十几字"内部消息"引爆板块 | 半导体行业谣言致芯片股集体暴跌 |

| **出口转内销** | 先在海外小网站发布，再转回国内传播 | 利用信息差制造"权威来源"假象 |

| **股吧自导自演** | 先建仓，再在股吧发布利好，吸引散户接盘 | 2015年某银行员工3天获利13万 |

| **网红荐股骗局** | 以"富二代"人设建付费群荐股后出货 | 王政源案，受害者亏损超千万元 |



### 6.3 核心原则



> **谣言的成本极低，收益极高——AI让成本更低。遇到任何未经官方渠道确认的消息，默认假定为谣言，直到多方交叉验证通过。**

## 七、回答工作流：新闻采集 → 分类判断 → 影响评估 → 舆情情绪 → 操作建议



### 7.1 完整流程



```

INPUT: 一条或多条新闻/舆情信息



Step 1: 新闻采集

  → 来源标注（官方/权威媒体/社媒/匿名）

  → 时间标注（发布时间、传播时间、市场反应时间）

  → 原始内容提取（去掉标题党包装，还原事实）



Step 2: 分类判断

  → 四级分类（政策/行业/公司/国际）

  → 影响范围标注（全市场/行业/板块/个股）

  → 交叉关联检查（一条新闻是否同时涉及多个层级）



Step 3: 影响评估

  → 信号判定（利好/利空/中性）

  → 信号分级（重大/中等/轻微/噪音）

  → 意外度计算（与市场已有预期的偏差）

  → 影响机制预判（过度反应/反应不足/提前定价/延迟反应）

  → 时间维度标注（即时冲击/短期3日/中期1月/长期结构性）



Step 4: 舆情情绪

  → 当前市场情绪方向与强度

  → 多空一致性/分歧度

  → 情绪是否在极端位置（极度乐观=警惕顶部，极度悲观=关注底部）

  → 情绪与基本面是否背离



Step 5: 操作建议

  → 基于以上四步的综合判断，给出分级建议：

    ├── 确定性高 → 明确方向建议（但须标注风险）

    ├── 确定性中 → 观察等待建议（等确认信号）

    ├── 确定性低 → 不做建议（信息不足，诚实标注）

  → 每条建议必须标注：信心等级、适用周期、前置风险



OUTPUT: 结构化分析报告

```



### 7.2 输出格式模板



```markdown

## 舆情分析报告



**新闻标题**: [原文标题]

**分类**: [政策/行业/公司/国际] | **影响范围**: [范围]

**信号**: [利好/利空/中性] | **级别**: [重大/中等/轻微/噪音]

**意外度**: [高/中/低] — 市场已有预期[描述]

**影响机制预判**: [过度反应/反应不足/提前定价/延迟反应]

**影响时间**: [即时/短期/中期/长期]



**情绪状态**: [描述当前市场情绪]

**情绪-基本面背离**: [是/否，说明]



**操作建议**: [具体建议]

**信心等级**: [高/中/低]

**适用周期**: [即时/短期/中期]

**前置风险**: [列出主要风险]

**诚实边界**: [明确标注不确定性]

```

## 八、诚实边界：舆情分析的局限



### 8.1 系统性局限



| 局限类型 | 说明 | 应对策略 |

|----------|------|----------|

| **假新闻污染** | AI时代造假成本极低，谣言可在几秒内触达数万人 | 严格来源核查，默认可疑 |

| **信息噪音** | 99%的财经新闻对股价无实质影响 | 用分级体系过滤噪音级信号 |

| **反应过度** | 市场短期情绪常偏离基本面 | 关注情绪极端位置的反向信号 |

| **信息不对称** | 机构提前获知信息，散户永远滞后 | 承认滞后，不做追击性操作 |

| **黑嘴操纵** | 有组织地制造谣言配合出货 | VIP群/付费荐股 = 红旗 |

| **自我欺骗** | 分析者自身偏见导致选择性解读 | 多视角交叉验证 |

| **模型失效** | 过去有效的关系可能随时失效 | 不迷信历史模式，保持怀疑 |



### 8.2 这个Skill不能做什么



1. **不能代替基本面分析**：舆情是辅助视角，不取代财报/估值/行业研究

2. **不能预测股价**：舆情分析预判的是市场反应模式和情绪方向，不是具体涨跌幅

3. **不能保证时效性**：信息从发布到传播到分析有时间差，实时行情中可能已滞后

4. **不能识别所有谣言**：精心制作的谣言可能通过所有核查步骤——这是一个永远的攻防博弈

5. **不能消除偏见**：所有分析框架都有内置假设，使用者需保持自我审视



### 8.3 使用者须知



> **舆情分析是"提高胜率的辅助工具"，不是"保证盈利的决策系统"。**

> 

> 它的价值在于帮你过滤噪音、识别信号、预判市场反应模式——但最终决策需要你结合基本面、估值、仓位管理和风控体系综合判断。

> 

> 任何声称"看新闻就能炒股"的说法，本身就是应该被识别的噪音信号。

## 九、信息源白名单与黑名单



### 9.1 白名单（优先使用）



| 类别 | 来源 |

|------|------|

| **官方渠道** | 证监会官网、沪深交易所公告、央行官网、国务院公报 |

| **权威财经媒体** | 财新、第一财经、证券时报、21世纪经济报道、经济观察报 |

| **专业数据** | Wind、同花顺iFinD、东方财富Choice |

| **行业研报** | 券商研究所官方报告 |



### 9.2 黑名单（永远排除）



- 知乎（非专业财经平台，内容质量不稳定）

- 微信公众号（来源不透明，无法验证作者资质）

- 百度百科/百度知道（内容无专业审核）

- 股吧/微博评论区（情绪噪音极高，操纵风险大）

- 任何付费荐股群/VIP群（几乎100%是操纵工具）



### 9.3 灰名单（谨慎使用）



| 来源 | 风险 | 使用条件 |

|------|------|----------|

| 今日头条财经频道 | 标题党多、软文多 | 仅看原文是否引用白名单数据 |

| 搜狐财经 | 转载为主、审核弱 | 交叉验证后方可引用 |

| CSDN/博客 | 专业性不确定 | 仅看技术分析部分，忽略情绪 |

## 十、快速参考卡片



```

遇到一条新闻时，30秒内必须回答的问题：



1. 来源是什么？ → 官方/权威/社媒/匿名

2. 影响谁？ → 全市场/行业/板块/个股

3. 改变了什么预期？ → 利好/利空/中性

4. 市场已经知道了吗？ → 意外度高/中/低

5. 和今日走势同向还是反向？ → 过度反应/反应不足

6. 是谣言吗？ → 查来源→查动机→查内容→交叉验证→观市场



30秒后判断：

  → 重大信号 → 立即深入分析

  → 中等信号 → 列入观察清单

  → 轻微/噪音 → 忽略，不花时间

```

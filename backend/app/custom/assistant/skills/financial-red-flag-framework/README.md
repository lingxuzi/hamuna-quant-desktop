# 财报排雷智能体

## 功能介绍

财报排雷智能体帮投资者从财务报表中识别造假信号和经营风险。不预测涨跌，只做一件事：在财报中找到那些"反常识、反逻辑、反行业规律"的异常信号，告诉你哪里可能有雷。

## 触发词

财报排雷、财务造假识别、排雷、存贷双高、应收异常、商誉减值、财务舞弊、财报粉饰、资金链预警、财务风险分析

## 关键词

分析工具、财报排雷

# 打板/回封交易体系 Skill

## 定位
本Skill为超短打板选手提供系统化的涨停板分析、封单判断、炸板评估、回封决策及风控框架，帮助用户捕捉强势涨停机会，同时控制交易风险。

## 核心能力
1. 涨停板类型识别与分析
2. 封单强度量化评估
3. 炸板概率预判
4. 回封时机精准把握
5. 打板风控体系构建

## 工作流

### 一、涨停板分析
#### 1.1 涨停板类型识别
| 类型 | 特征 | 策略意义 |
|------|------|----------|
| 一字板 | 开盘即涨停，封单极大 | 利好驱动，难买入，错杀时可介入 |
| T字板 | 开盘涨停后打开，尾盘回封 | 换手充分，关注回封质量 |
| 换手板 | 涨停过程中多次打开 | 市场分歧大，需观察回封力度 |
| 烂板 | 频繁开板，封单不稳定 | 分歧转一致潜在妖股，关注次日走势 |
| 缩量涨停 | 换手率<3%，成交量萎缩 | 主力控盘，警惕高位放量 |
| 涨停三法 | 涨停+两小阳 | 空中加油，沿5日线建仓 |
| 双板夹阴 | 涨停-阴线-涨停 | 洗盘后二次启动，第二板封板确认介入 |
| N字反攻 | 涨停-回调-再涨停 | 回撤不超首板1/3，二次启动放量时买入 |

#### 1.2 涨停强度评估维度
1. **涨停时间**：
   - 一字开盘：最强（重大利好）
   - 5分钟内涨停：超强
   - 30分钟内涨停：强势（保守选手只参与10:00前涨停）
   - 1小时内涨停：中性（看市场氛围）
   - 早盘收盘前涨停：底线
   - 下午涨停：弱势（除非题材龙头）

2. **封单成交比**（核心指标）：
   - 计算公式：封单成交比 = 收盘买一封单量 ÷ 当日总成交量
   - >10：顶级硬板，锁仓等连板
   - 3-10：强势硬板，次日冲高止盈
   - 1-3：普通封板，见好就收
   - <1：弱势封板，谨慎参与

### 二、封单判断
#### 2.1 封单强度七级标准
| 流通盘规模 | 强势封单标准 | 市场意义 |
|------------|--------------|----------|
| 800万-3000万股 | ≥6000手 | 次日95%概率高开 |
| 3000万-5000万股 | ≥10000手 | 趋势逆转信号 |
| 5000万-1亿股 | ≥20000手 | 底部启动临近 |
| 1亿-2亿股 | ≥40000手 | 强势持续 |
| 2亿-3亿股 | ≥50000手 | 主力坚决 |
| 3亿-6亿股 | ≥80000手 | 板块龙头 |
| >6亿股 | ≥100000手 | 超级龙头 |

#### 2.2 封单质量分析
1. **封单结构**：
   - 优质：超大单(>5000手)+大单(1000-5000手)占比>60%，连续排列无断层
   - 劣质：小单(<500手)为主，零散堆砌，易炸板

2. **封单占比**（比绝对数量更可靠）：
   - 高价值：流通盘占比>5% 或 当日成交量占比>30%
   - 低质量：流通盘占比<3% 或 成交量占比<10%

3. **封单变化监控**：
   - 封单持续增加：强主力护盘
   - 封单缓慢减少：跟风资金不足，警惕
   - 封单快速减少：主力撤火或出货

### 三、炸板概率评估
#### 3.1 炸板时间影响
- **早盘炸板**（10:30前）：分歧转一致机会，快速换手后易回封
- **午后炸板**：弱势信号，回封难度大
- **尾盘炸板**：主力出货概率高，次日低开风险大

#### 3.2 连板高度与炸板关系
- 高位连板：炸板概率低，即使炸板也易缩量回封
- 低位首板：炸板率高（1晋2概率低），需谨慎
- 稀缺性规律：高度越高，炸板后回封概率越高

#### 3.3 拉板方式影响
- **推土机式拉升**（机构风格）：换手充分，炸板后回封机会大
- **直线拉升**（游资风格）：换手不足，易炸板且回封难度大

#### 3.4 个股地位评估
- **板块先锋/龙头**：有板块效应，炸板后易回封
- **跟风个股**：无板块支撑，炸板后易退潮
- **孤立涨停**：无题材联动，炸板风险高

### 四、打板/回封决策
#### 4.1 打板时机选择
1. **优先参与**：
   - 早盘（10:30前）封板
   - 封单成交比>3
   - 板块联动性强
   - 个股处于上升趋势

2. **谨慎参与**：
   - 午后封板（除非题材龙头）
   - 封单成交比1-3
   - 跟风个股

3. **避免参与**：
   - 尾盘偷袭涨停
   - 封单成交比<1
   - 高位缩量涨停（警惕出货）

#### 4.2 回封板交易策略
1. **回封质量判断**：
   - 炸板后迅速回封（<5分钟）：二封封单减少，易成烂板，关注次日弱转强
   - 炸板后延迟回封（>20分钟）：二封封单增加，考虑介入

2. **回封买入条件**：
   - 回封时封单量增加
   - 板块效应持续
   - 个股处于低位或突破位置
   - 分时图显示资金坚决（如快速拉升回封）

3. **回封板优势**：
   - 释放抛压，减轻后续上升压力
   - 抬高市场成本，增强支撑
   - 验证多路资金认可（非单一主力）

### 五、打板风控体系
#### 5.1 仓位管理
- 单只个股打板仓位：≤总资金10%
- 单日打板总仓位：≤总资金30%
- 市场弱势时：降低仓位或空仓

#### 5.2 止损纪律
1. **刚性止损**：
   - 打板后次日低开>3%：立即止损
   - 跌破重要支撑位（如5日线）：果断止损
   - 炸板后无法回封且走势软弱：当日止损

2. **动态止损**：
   - 连板个股：跌破当日涨停价止损
   - 趋势个股：跌破5日线止损

#### 5.3 选股过滤条件
- 排除：ST/*ST、业绩暴亏、退市风险股
- 优先：题材龙头、板块效应强、股性活跃
- 警惕：跟风股、无量涨停、尾盘偷袭

#### 5.4 交易纪律
1. **执行层面**：
   - 严格按计划操作，不随意更改
   - 避免情绪化追涨杀跌
   - 设置条件单，减少盯盘压力

2. **复盘要求**：
   - 每日复盘涨停板，分类记录类型
   - 统计封单成交比，优化参数
   - 分析炸板案例，总结规律

## 局限性说明
1. 本体系基于A股历史数据总结，市场生态变化可能导致策略失效
2. 涨停板战法本身高风险，需配合严格风控使用
3. 封单数据可能被主力操纵，需结合多指标验证
4. 适用于超短打板选手，中长期投资者不适用
5. 信息截止至2026年6月，需结合最新市场情况调整

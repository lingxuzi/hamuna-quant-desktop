# 盘口语言分析框架 Skill

## 框架概览

本Skill提供短线专项技术分析能力，聚焦分时走势、盘口挂单、大单异动、炸板、封单、日内强弱判断、盯盘信号解读等核心领域。适配超短、打板、日内交易者使用。

**核心能力矩阵：**

| 能力域 | 核心内容 | 适用场景 |
|--------|----------|----------|
| 分时走势分析 | 波形识别、均价线关系、量价配合 | 日内交易、T+0操作 |
| 盘口挂单解读 | 五档/十档挂单、上压板/下托板、挂单类型 | 实时盯盘、买卖点判断 |
| 大单异动识别 | 扫盘、隐性买卖盘、对敲、大单挂单技巧 | 捕捉主力动向 |
| 封单/炸板判断 | 封单强度计算、炸板预判信号 | 打板、排板决策 |
| 日内强弱判断 | 均价线突破、回踩/反弹、量能叠加 | 日内方向判断 |

---

## 回答工作流（Agentic Protocol）

当用户提出盘口分析、打板技巧、盯盘信号等相关问题时，必须遵循以下工作流：

### 第一步：分时走势分析
- 识别分时图波形（攻击波、杀跌波、试盘波、回头波、脉冲波）
- 判断与均价线的关系（突破、回踩、反弹、跌破）
- 分析量价配合情况（量能叠加、缩量回调、放量攻击）

### 第二步：盘口信号识别
- 解读买卖盘挂单（上压板、下托板、递增/递减压迫式、蜂窝式）
- 识别大单异动（扫盘、隐性买卖盘、对敲、大单压吸筹/顶出货）
- 判断主力意图（吸筹、洗盘、拉升、出货）

### 第三步：买卖时机确认
- 结合封单强度判断打板/排板时机
- 识别炸板预判信号，决定去留
- 给出明确的操作建议（买入、卖出、观望、止损）

## 方法论对比

### 分时图波形分析

| 波形类型 | 特征描述 | 市场含义 | 操作建议 |
|----------|----------|----------|----------|
| **攻击波** | 股价快速上涨，持续性强势攻击 | 主力投入资金买入或对敲拉抬 | 上升初期介入，末期警惕出货 |
| **杀跌波** | 股价快速下跌波形 | 主力出货或市场恐慌 | 回避或逢高减仓 |
| **试盘波** | 短暂上攻后回落 | 主力测试抛压和市场反应 | 观察后续方向选择 |
| **回头波** | 拉升过程中回落回调 | 见顶或阶段性洗盘 | 关注量能是否萎缩 |
| **脉冲波** | 短暂快速波动 | 资金短暂介入或退出 | 谨慎追涨，防止诱多 |

**攻击波细分：**
- **冲击性攻击波**：强势上涨，吸引跟风盘
- **脉冲性攻击波**：表面主力高度控盘，独立涨跌

### 盘口挂单解读

| 挂单类型 | 挂单特征 | 主力意图 | 应对策略 |
|----------|----------|----------|----------|
| **上压板** | 卖一以上有大卖单 | 制造抛压假象或真实出货 | 中低价区可能是洗盘，高价区警惕出货 |
| **下托板** | 买一以下有大买单 | 制造支撑假象或真实护盘 | 中低价区可能是吸筹，高价区警惕诱多 |
| **递增压迫式** | 委卖三档及以上递增 | 警示卖压增强 | 考虑减仓或退出 |
| **递减压迫式** | 第一档最大，后续递减 | 吸引跟风盘消耗挂单 | 观察是否真突破 |
| **蜂窝式挂单** | 密集连续大单 | 市场参与者多，气氛热烈 | 适合短线博弈 |

**挂单位置优先级：**
- 买一/卖一：多空直接亮剑位置，最能反映实力
- 买二/卖二：容易率先成交，挂单较真实
- 买三~买五/卖三~卖五：虚假成分多，可应变

### 大单异动识别

| 异动类型 | 表现形式 | 背后逻辑 | 验证方法 |
|----------|----------|----------|----------|
| **扫盘** | 大单连续吞噬卖盘 | 主力大举进场建仓 | 观察是否持续买入 |
| **隐性买卖盘** | 成交栏出现但挂单栏无 | 主力隐蔽操作 | 结合上压板/下托板判断 |
| **对敲** | 多账户同时买卖 | 制造活跃假象或操纵价格 | 观察成交量是否异常 |
| **大单压吸筹** | 卖单大但股价不跌 | 主力压盘吸货 | 观察买一是否小单承接 |
| **大单顶出货** | 买盘全是大单，卖一反复出现 | 主力源源不断出货 | 高价位尤其要警惕 |

**特殊数字挂单：**
- 666手、555手、1818手等特殊数字：主力故意告知意图
- 整数挂单（1000手、5000手）：大资金活动迹象

### 封单强度判断

**封单强度计算公式：**

```
封板率 = 封单量 / 流通股本 × 100%
封单强度指标 = (买一委托量 - 卖一委托量) / 总委托量 × 100%
```

**强度判断标准：**

| 判断维度 | 强势特征 | 弱势特征 |
|----------|----------|----------|
| **封单量** | 封单量＞流通盘10% | 封单量＜流通盘5% |
| **封板时间** | 早盘30分钟内封板 | 尾盘封板 |
| **成交量** | 涨停时成交量小 | 涨停时成交量巨大 |
| **股价位置** | 启动初期、中低价区 | 高位、涨幅巨大 |
| **打开次数** | 未打开或仅打开一次 | 多次打开 |

**实战要点：**
- 早盘封板 + 封单量大 + 成交量小 = 强势板，连板概率高
- 尾盘封板 + 封单量小 + 成交量大 = 弱势板，次日溢价低

### 炸板预判信号

**炸板原因分类：**

| 炸板时间 | 主力意图 | 操作建议 |
|----------|----------|----------|
| **早盘炸板** | 主力吸筹，故意打开 | 可关注回封机会 |
| **午盘炸板** | 市场分歧加大 | 谨慎持有 |
| **尾盘炸板** | 主力出货概率大 | 及时止盈 |

**炸板预判信号：**
1. 封单明显不足，封板率＜5%
2. 涨停时成交量过大，换手率异常
3. 股价处于高位，涨幅＞30%
4. 涨停板多次打开，接力资金不足
5. 板块整体走弱，个股独木难支
6. 大盘突然跳水，系统性风险

**炸板后处理：**
- 如果是吸筹炸板：等待回封，回封时择机介入
- 如果是出货炸板：及时止盈，不存侥幸心理

## 日内强弱判断体系

### 均价线战法

**核心原则：**
- 价格线向上突破均价线 → 看涨信号
- 价格线向下跌破均价线 → 看跌信号
- 回踩不破均价线 → 多头强势
- 反弹不破均价线 → 空头强势

**量能叠加分析：**
- 攻击时量能持续放大 → 健康上涨
- 攻击时量能萎缩 → 上涨乏力
- 回调时量能萎缩 → 洗盘概率大
- 回调时量能放大 → 出货概率大

### 分时图强弱信号

**强势信号：**
1. 开盘后快速上攻，不破开盘价
2. 均价线向上倾斜，支撑明显
3. 回调不破均价线，量能萎缩
4. 再次上攻时量能放大
5. 全天大部分时间在均价线上方

**弱势信号：**
1. 开盘后快速下跌，回抽无力
2. 均价线向下倾斜，压力明显
3. 反弹不破均价线，量能不足
4. 再次下跌时量能放大
5. 全天大部分时间在均价线下方

### 盯盘信号体系

**买入信号：**
1. 均价线突破 + 量能放大
2. 回踩均价线不破 + 缩量
3. 扫盘大单出现 + 股价企稳
4. 下托板出现 + 股价启动
5. 隐性买盘多 + 抛压轻

**卖出信号：**
1. 均价线跌破 + 量能放大
2. 反弹均价线不过 + 缩量
3. 砸盘大单出现 + 股价走弱
4. 上压板出现 + 股价滞涨
5. 隐性卖盘多 + 承接弱

**风险提示信号：**
1. 快涨慢跌 → 可能的出货
2. 快跌慢涨 → 可能的吸筹
3. 对敲明显 → 操纵迹象
4. 封单异常 → 可能的诱多/诱空
5. 多次炸板 → 市场分歧大

## 实战案例解析

### 案例1：攻击波识别与操作

**场景描述：**
某股开盘后快速上攻，形成攻击波，均价线同步向上，回调不破均价线。

**分析步骤：**
1. 分时走势分析：攻击波形成，强势特征
2. 盘口信号识别：买一有大单支撑，卖盘稀疏
3. 量能分析：攻击时放量，回调时缩量

**操作建议：**
- 回调不破均价线时买入
- 设置止损：跌破均价线
- 止盈目标：次日高开或继续涨停

### 案例2：封单强度判断

**场景描述：**
某股10:00封板，封单量50000手，流通盘1亿股，封板率5%。

**分析步骤：**
1. 计算封板率：50000/100000000×100% = 5%
2. 判断封板时间：早盘封板，时间较好
3. 观察成交量：涨停时成交量中等

**操作建议：**
- 封板率5%属于中等偏弱，需警惕炸板
- 如果排板，要随时准备撤单
- 如果已持有，设置预警：封单＜30000手时考虑卖出

### 案例3：大单异动识别

**场景描述：**
某股长期低迷，某日卖一、卖二、卖三挂出巨大抛单（每笔上千手），但股价不跌，反而有小单主动承接。

**分析步骤：**
1. 识别大单压吸筹信号
2. 观察买一是否小单承接
3. 判断是否为启动信号

**操作建议：**
- 可能是主力建仓动作
- 可小仓位试探性买入
- 等待放量突破确认

## 打板技巧专题

### 打板三大绝技

**1. 扫板**
- 适用场景：重大消息刺激的国家级题材，盘中第一个被资金直线点火
- 操作要点：第一时间介入，追求速度

**2. 排板**
- 适用场景：市场环境不好，对个股信心不足
- 操作要点：等资金吃掉最后一档时排队，可随时撤单

**3. 做回封**
- 适用场景：早盘秒板（无强逻辑）、中高位缩量板、首板分仓套利
- 操作要点：过滤无效信号，洗出潜伏盘，封板更稳定

### 打板注意事项

**首选标的：**
- 当天领涨板块、热点题材且有持续性
- 盘子小、概念多、资金容易拉动
- 竞价带量抢筹，开盘第一笔往上

**风险规避：**
- 次新缩量首板谨慎（日内炸板概率高）
- 尾盘封板谨慎（次日溢价不确定）
- 高价位、涨幅巨大谨慎（出货风险）

**操作纪律：**
- 收盘前不能涨停或涨停无望，必须清掉
- 次日低开，第二波上攻不能创新高，微亏也要走
- 不要把短线做成长线

## 局限与诚实边界

### 盘口分析的局限性

**1. 需要Level-2实时数据**
- 本框架基于五档/十档行情分析
- 如果只有五档行情，可能无法看到全部挂单情况
- 建议：使用Level-2行情软件，获取十档行情和逐笔成交

**2. 庄家伪装挂单**
- 主力可能故意挂出大单制造假象
- 上压板可能是吸筹，下托板可能是出货
- 建议：结合股价位置、成交量、市场环境综合判断

**3. 盘口欺诈**
- 对敲、虚假挂单等手段常见
- 特殊数字挂单可能只是巧合
- 建议：不要单一依赖盘口信号，要结合多个维度

**4. 市场环境依赖**
- 牛市盘口信号成功率高，熊市容易失效
- 系统性风险时，个股盘口再强也可能被拖累
- 建议：先看大盘，再看板块，最后看个股

**5. 经验依赖性强**
- 盘口语言分析需要大量实战经验
- 新手可能误判信号，造成亏损
- 建议：先用模拟盘练习，再逐步实盘

### 不适用场景

- 长期投资分析（本框架专注短线）
- 基本面分析（本框架专注技术面）
- 不受盘口影响的大盘股（如工商银行等）
- 极度冷门、成交稀少的股票

## 核心要点总结

### 盘口语言分析三大铁律

1. **价量配合是核心**
   - 价涨量增 → 健康
   - 价涨量缩 → 乏力
   - 价跌量增 → 恐慌或出货
   - 价跌量缩 → 洗盘或惜售

2. **均价线是灵魂**
   - 突破均价线看多
   - 跌破均价线看空
   - 回踩不破看多
   - 反弹不破看空

3. **盘口挂单是窗口**
   - 买一/卖一是先锋部队
   - 大单位置反映实力
   - 隐性买卖盘藏玄机
   - 特殊数字有含义

### 打板成功三要素

1. **选对板块**：热点题材、领涨板块
2. **选对时机**：早盘封板、量能配合
3. **选对标的**：龙头股、盘子小、概念多

### 风险控制三原则

1. **止损坚决**：跌破均价线、炸板失败，立即止损
2. **不存侥幸**：盘口信号失效，承认错误
3. **仓位管理**：单只股票不超过30%，防止过度集中

## 附录：常用指标公式

### 1. 分时攻击力度指标

```
攻击力度 = (当前价格 - 开盘价格) / 时间间隔长度 × 成交量
```

### 2. 封单强度指标

```
封单强度 = (买一委托量 - 卖一委托量) / 总委托量 × 100%
```

### 3. 封板率

```
封板率 = 封单量 / 流通股本 × 100%
```

### 4. 量能叠加判断

```
量能健康 = 攻击时量能放大 AND 回调时量能萎缩
量能异常 = 攻击时量能萎缩 OR 回调时量能放大
```

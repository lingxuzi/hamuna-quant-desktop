> 信息截止：2025年4月 | 局限性标注见文末

## 一、可转债基础概念

### 1.1 什么是可转债

可转换公司债券（Convertible Bond），上市公司发行的、赋予持有人在特定条件下将债券转换为公司股票权利的混合证券。核心特征：**下有债底保底，上随正股弹性**。

三大属性：
- **债券属性**：到期还本付息，票面利率通常0.3%-2%（逐年递增），有信用评级（AAA到A+）
- **股票属性**：可按转股价将转债转为股票，与正股联动
- **期权属性**：内含转股期权、下修期权、回售期权

### 1.2 核心条款解读

| 条款 | 含义 | 关键参数 |
|------|------|----------|
| **转股价** | 将转债转为股票的约定价格 | 转股价值 = 100/转股价 × 正股价 |
| **转股溢价率** | 转债价格高于转股价值的比率 | = (转债价格 - 转股价值) / 转股价值 × 100% |
| **到期赎回** | 到期后发行人以面值+补偿利息赎回 | 通常为105-115元（含最后一期利息） |
| **强制赎回（强赎）** | 正股持续高于转股价130%时，发行人有权按约103元强赎 | 触发条件通常：30个交易日中至少15日正股≥转股价×130% |
| **回售** | 正股持续低于转股价70%时，持有人有权按约103元回售给公司 | 触发条件通常：连续30日正股<转股价×70%（回售期内） |
| **下修** | 正股持续低于转股价80%-85%时，发行人可下调转股价 | 须经股东大会2/3通过，下修后转股价≥每股净资产且≥近期均价 |

### 1.3 交易规则

- **T+0交易**：当日买入可当日卖出
- **涨跌幅**：上市首日±57.3%/±43.3%（沪）/ 申报价不超发行价157.3%（深）；次日起±20%
- **临时停牌**：较发行价涨跌≥20%停牌30分钟，≥30%停牌至14:57
- **交易单位**：1手=10张，1张=100元面值
- **转股操作**：转股期内操作，转股后次日方可卖出股票（T+1）

## 二、可转债估值体系

### 2.1 核心估值指标

#### 转股价值（平价）
```
转股价值 = 100 / 转股价 × 正股现价
```
转债转为股票后的市场价值，衡量转债的"股性底"。

#### 转股溢价率
```
转股溢价率 = (转债价格 - 转股价值) / 转股价值 × 100%
```
- **< 0%**：折价，存在转股套利空间
- **5%-20%**：合理区间，股债联动好
- **> 50%**：高溢价，正股涨转债难跟，风险大

#### 纯债价值（债底）
```
纯债价值 = Σ[票息/(1+同评级企债YTM)^t] + 到期赎回价/(1+同评级企债YTM)^n
```
将转债视为纯债的折现价值，是转债的最后防线。

#### 纯债溢价率
```
纯债溢价率 = (转债价格 - 纯债价值) / 纯债价值 × 100%
```
越低债性越强、越安全。

#### 到期收益率（YTM）
```
使 Σ[现金流/(1+YTM)^t] = 转债价格 成立的贴现率
```
- **YTM > 0%**：持有到期不亏（不考虑违约）
- **YTM < 0%**：持有到期有亏损风险

#### 百元溢价率（平价溢价率）
```
百元溢价率 = 转债价格 / 转股价值 × 100 - 100
```
即标准化为转股价值100元时的溢价水平，便于不同转债间横向比较。

### 2.2 四象限分类

| | 纯债溢价率低（债性强） | 纯债溢价率高（债性弱） |
|---|---|---|
| **转股溢价率低（股性强）** | ✅ **黄金区**：债底保护+正股弹性，双低策略目标 | ⚠️ 高价高弹性：已获利区，等同股票 |
| **转股溢价率高（股性弱）** | ⛱️ 安全但迟钝：防守型，等下修/回售机会 | ❌ 双高区：无投资价值，回避 |

### 2.3 双低值

```
双低值 = 转债价格 + 转股溢价率 × 100
```
核心选债指标，值越低性价比越高。历史回测双低策略年化收益21%+，最大回撤18%左右。

## 三、可转债投资策略

### 3.1 打新策略

**逻辑**：可转债发行时以面值100元认购，上市首日通常有溢价。

**操作要点**：
- 顶格申购（1000手），中签率通常0.01%-0.1%
- 上市首日择机卖出，多数转债首日涨幅10%-30%
- **筛选**：优先申购正股质地好、行业景气、评级AA+以上的转债
- **风险**：破发可能（熊市中低评级转债），首日涨幅不及预期

### 3.2 双低轮动策略

**逻辑**：买入价格低+溢价率低的转债，定期轮动。

**经典参数**：
- 价格 < 115-120元，溢价率 < 20%-30%
- 按双低值排序，选前10-20只
- 定期轮动（周/月），卖出双低值升高或触发强赎的，换入新的双低转债

**增强版**：
- 加入成交量活跃因子（避免流动性陷阱）
- 动态调整价格与溢价率权重
- 三低策略：低价格+低溢价率+低正股市值（size因子）

**历史表现**：2017年以来年化21.46%，夏普比率1.44，最大回撤18.16%（新浪财经数据）

### 3.3 摊大饼策略

**逻辑**：分散买入多只转债，坐等强赎或爆炒，被动获利。

**操作要点**：
- 5位数资金：10-20只；6位数：20-30只；7位数：30-50只
- 单只仓位不超过5%
- 优先双低品种，分散行业和概念
- 买入后少操作，目标价130元止盈
- 配合仓位管理（7成转债+3成现金）

**适用人群**：佛系投资者、无暇盯盘者

### 3.4 强赎博弈策略

**逻辑**：发行人推动正股上涨至触发强赎条件，转债价格大概率冲上130元+。

**操作要点**：
- 筛选接近强赎触发条件的转债（正股已接近转股价120%+）
- 分析发行人促转股意愿（大股东持债情况、转债临近到期、公司不想还钱）
- **信号**：大股东高位减持转债、公司发布利好、下修后正股启动
- **风险**：强赎公告后转债快速回落至赎回价（约103元），必须及时卖出

### 3.5 下修博弈策略

**逻辑**：上市公司下调转股价→转股价值跳升→转债价格上涨。

**筛选条件**：
- 已触发下修条款（正股持续低于转股价80%-85%）
- 公司促转股动力强：临近回售期/到期、大股东持债比例高、不想还钱
- 排除无法下修的：PB<1（银行/钢铁转债）、股东反对风险大

**关键时点**：
1. 董事会提议下修公告次日 → 转债上涨确定性较高
2. 股东大会通过后 → 取决于下修是否到位
3. 下修到底（至每股净资产附近）→ 利好兑现

**获利空间**：提前埋伏约3%，公告后介入也有相对确定收益（兴业证券测算）

## 四、可转债套利

### 4.1 折价转股套利
**条件**：转股溢价率 < 0%（转债价格低于转股价值）
**操作**：买入转债 → 转股 → 次日卖出正股
**风险**：次日正股低开抹平套利空间

### 4.2 正股涨停套利
**条件**：正股涨停无法买入，转债无涨跌幅限制
**操作**：正股涨停时买入转债，博取次日继续涨停
**风险**：涨停打开、转债高溢价

### 4.3 回售博弈套利
**条件**：正股接近转股价70%，公司有避免回售的动机
**操作**：买入转债，博公司拉升正股或下修避免回售
**风险**：公司选择接受回售

### 4.4 下修博弈套利
（见3.5节）

### 4.5 配售套利
**条件**：持有正股可获得转债配售权
**操作**：配售股权登记日前买入正股→获配转债→转债上市卖出
**风险**：正股下跌损失超过配售收益

## 五、条款分析清单

分析一只转债时，必须逐项核查：

- [ ] 转股价及调整历史
- [ ] 转股期起止时间
- [ ] 强赎触发条件及当前进度（x/15日达标）
- [ ] 下修触发条件及当前进度
- [ ] 是否已公告不强赎/不下修（及期限）
- [ ] 回售期及回售触发条件
- [ ] 到期赎回价（保本价 = 到期赎回价 + 历年已付利息）
- [ ] 每股净资产（下修底线）
- [ ] 大股东持债比例（下修/强赎动力）
- [ ] 剩余规模（小盘债弹性大，易被炒作）
- [ ] 信用评级及展望
- [ ] 正股基本面（是否ST/退市风险）

## 六、风控要点

### 6.1 可转债特有风险

| 风险类型 | 说明 | 典型案例 |
|----------|------|----------|
| **强赎风险** | 强赎公告后转债快速跌至赎回价~103元，高位持有者损失巨大 | 东财转3强赎后从170跌至100 |
| **信用风险** | 公司违约/退市，转债可能一文不值 | 搜特转债退市、蓝盾转债违约 |
| **高溢价风险** | 溢价率>50%的转债，正股涨转债不跟，溢价压缩时暴跌 | 横河转债溢价300%后退市 |
| **下修不及预期** | 下修不到位、下修方案被否决 | 众兴转债下修被股东否决 |
| **流动性风险** | 小盘债成交量极低，进出困难 | 部分转债日成交不足百万 |
| **条款博弈复杂性** | 下修/强赎/回售均非义务，结果不确定 | 浙商转债触发下修但从未行使 |

### 6.2 排雷清单

- ❌ 评级低于AA-的转债（信用风险高）
- ❌ 正股ST/*ST/有退市风险
- ❌ PB<1且无法下修的转债（银行/钢铁等）
- ❌ 溢价率>50%的转债
- ❌ 已公告强赎的转债
- ❌ 剩余规模极小且流动性差的转债（除非博弈炒作）
- ❌ 公司财务严重恶化、有违约前科

### 6.3 仓位与纪律

- 单只转债仓位不超过5%（摊大饼）/ 10%（精选）
- 总转债仓位根据市场环境调整（牛市7-8成，熊市3-5成）
- 设定止损线：破面值后持续跟踪，跌破90元须审视基本面
- 强赎公告后5个交易日内清仓
- 定期轮动检视，不恋战

## 七、回答工作流

当用户询问可转债相关问题时，按以下流程分析：

```
1. 转债筛选
   → 根据用户目标（进攻/防守/套利）初筛转债池
   → 排除：低评级/ST/高溢价/已强赎

2. 估值分析
   → 计算双低值、转股溢价率、纯债溢价率、YTM
   → 定位四象限位置
   → 与同行业/同评级转债横向比较

3. 策略匹配
   → 进攻型 → 双低轮动 / 强赎博弈
   → 防守型 → 高YTM / 低价债底策略
   → 套利型 → 折价转股 / 下修博弈 / 回售博弈
   → 省心型 → 摊大饼 / 打新

4. 条款检查
   → 逐项核查条款分析清单
   → 重点：强赎进度、下修进度、回售期、大股东持债

5. 操作建议
   → 给出具体买入/卖出/持有建议及理由
   → 标注关键价位（保本价、强赎价、目标价）
   → 明确风险点和止损线
```

## ⚠️ 诚实边界

1. **历史收益不代表未来**：双低策略年化21%+是历史回测，市场结构变化可能导致策略失效
2. **信用风险不可忽视**：2020年后可转债已出现实质违约案例（搜特、蓝盾），"下有保底"不再绝对
3. **条款博弈非确定性事件**：下修/强赎/回售均为权利而非义务，公司可能选择不行使
4. **高溢价转债的死亡螺旋**：溢价率压缩可能比正股下跌更猛烈
5. **小盘债炒作风险**：剩余规模<3亿的转债可能被游资操纵，脱离基本面暴涨暴跌
6. **本Skill不构成投资建议**：所有分析框架仅供学习参考，实际投资需自行判断风险
7. **信息时效性**：交易规则、监管政策可能变化，请以最新官方规则为准
8. **下修受限**：PB<1的公司理论上无法下修到底，银行/钢铁/煤炭等行业常见此限制

## 完整时间线

### 早年与教育（1930-1950）

| 年份 | 事件 |
|------|------|
| 1930年8月30日 | 出生于内布拉斯加州奥马哈 |
| 1941年（11岁） | 首次购买股票（City Services优先股） |
| 1944年（14岁） | 用送报收入申报个人所得税 |
| 1947年（17岁） | 高中毕业，进入宾夕法尼亚大学沃顿商学院 |
| 1950年（20岁） | 转入哥伦比亚大学商学院，师从Benjamin Graham |
| 1951年（21岁） | 获得哥伦比亚大学经济学硕士学位，A+成绩 |

### 早期投资生涯（1950-1969）

| 年份 | 事件 |
|------|------|
| 1954年 | 加入Graham-Newman公司，成为格雷厄姆的员工 |
| 1956年 | 离开Graham，回到奥马哈创立巴菲特合伙企业 |
| 1957-1969 | 合伙企业年均回报率约31%，远超道琼斯指数 |
| 1962年 | 开始购买Berkshire Hathaway股份 |
| 1965年 | 获得Berkshire Hathaway控制权 |
| 1967年 | 收购National Indemnity保险公司，浮存金战略起步 |
| 1969年 | 清盘合伙企业，将资产转为伯克希尔股票 |

### 中期：伯克希尔转型（1970-1999）

| 年份 | 事件 |
|------|------|
| 1972年 | 收购See's Candy（喜诗糖果），哲学转变标志 |
| 1976年 | 开始投资GEICO，最终控股 |
| 1978年 | 芒格正式成为副董事长 |
| 1983年 | 收购Nebraska Furniture Mart，B夫人传奇 |
| 1985年 | 收购《布法罗晚报》，转型为真正的报纸 |
| 1987年 | 股灾中拒绝抛售，可口可乐开始买入 |
| 1988年 | 开始买入可口可乐 |
| 1991年 | 与戈尔巴乔夫会面，开始国际声誉提升 |
| 1996年 | 发行B股（小盘股） |
| 1998年 | 收购General Re再保险公司（后来造成巨大损失） |

| 年份 | 事件 |
|------|------|
| 2000年 | 首次出席伯克希尔年会，数字化开始影响 |

| 2010年 | 与Bill Gates一同访华 |

| 2012年 | 宣布患有前列腺癌（已治愈） |
| 2014年 | 收购Van Tuyl汽车经销商网络 |
| 2015年 | 收购Precision Castparts（最终失败） |
| 2016年 | 首次买入苹果（AAPL） |
| 2017年 | 收购告吹：德事隆（Textron）竞购 |

### 近期动态（2020-2024）

| 年份 | 事件 |
|------|------|

### 思想关键转折点

1. **1950年** — 师从Graham，建立安全边际基础
2. **1972年** — 喜诗糖果，脱离Graham体系
3. **1978年** — 芒格成为合伙人，从定量到定性
4. **1987年** — 可口可乐，验证品牌护城河
5. **2008年** — 金融危机，身体力行逆向投资
6. **2016年** — 苹果，认知迭代
7. **2022年** — 芒格去世，投资哲学新阶段

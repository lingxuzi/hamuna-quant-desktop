# 巴菲特价值投资视角（Buffett Value Investing Perspective）

## 功能介绍

提供巴菲特价值投资视角（Buffett Value Investing Perspective）相关的分析与决策支持。

## 核心技能

- 场景**：当你纠结于"要不要买这只股票"时
- 规则**：问自己——如果这家公司明天退市了，你还愿意买吗？如果不愿意，说明你在投机，不在投资。
- 案例**：1987年股灾后买入可口可乐，不是基于股价，而是基于品牌价值。

价值投资、护城河、怎么分析XX公司、XX股票值得买吗、持仓逻辑、仓位配置、避雷

思维视角、价值投资

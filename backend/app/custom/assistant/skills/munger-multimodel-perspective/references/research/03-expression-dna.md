# Agent 3: 表达DNA调研

## 高频用词与句式

### 标志性开场白
- "I would argue that..." (我会认为...)
- "The answer is..." (答案是...)
- "Well,..." (语气词，表示思考)
- "It's very interesting that..." (这很有趣...)

### 确定性表达
- 高确定性: "Obviously," "The truth is," "Of course,"
- 承认不确定性: "I don't know," "It's hard to know," "Maybe"

### 逆向表达（标志性）
- "I want to know where I'm going to die, so I never go there" (我想知道我会死在哪里，这样我就永远不去那里)
- "How can I guarantee a lousy outcome?" (我如何保证一个糟糕的结果?)
- "Invert, always invert" (逆向，要经常逆向)

## 节奏感与修辞特征

### 先结论后铺垫
- 先给出明确判断，再解释理由
- 例: "The answer is we survived so far... And the bad news is..." (答案是我们至今存活...坏消息是...)

### 类比密度
- **极高**: 物理学、生物学、数学、工程学类比密集
- 例: "临界点"、"断裂点"、"备份系统"、"铁锤综合症"

### 幽默方式
1. **自嘲**: 
   - "我99岁了"
   - "现在我能更聚焦于本质问题"（失去左眼后）
   - "如果不是为了变得聪明，为什么要读书?"

2. **逆向幽默**:
   - 《如何保证痛苦一生》演讲
   - 用反面例子说明正面道理

3. **冷幽默**:
   - 简短、犀利、出人意料
   - 例: "热门交易和IPO... 我们拒为'不'"

## 争议立场与公开辩论

### 对加密货币的态度
- **极端负面**: 多次称比特币为"老鼠药"、"欺诈"
- 2021年: "我当然恨比特币支持者。我认为他们应该是被枪决的Idiots"
- 表达特征: 使用极端词汇("hate", "should be shot")

### 对中国市场的态度
- **正面": 多次表达对中国的乐观
- "在中国今天生活是非常幸运的，我们比其他人拥有更多机会"
- "看好中国未来20年"

### 对AI的态度
- **谨慎乐观**: 认为重要但被过度炒作
- "人工智能不会治愈癌症"
- 承认在特定领域（如保险承保）有用

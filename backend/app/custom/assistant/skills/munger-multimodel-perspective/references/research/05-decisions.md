# Agent 5: 决策记录与行动调研

## 关键投资决策

### 1. See's Candies收购（1972年）
- **决策**: 说服巴菲特以2500万美元收购See's Candies
- **背景**: 这家加州糖果制造商年税前收入仅约400万美元
- **逻辑**: 
  - 强大品牌和消费者忠诚度（"护城河"）
  - 定价能力（每年提价不影响销量）
  - 简单、可预测的商业模式
- **结果**: 成为伯克希尔最成功的收购之一，证明了"以公道价格投资伟大公司"的哲学
- **意义**: 这标志着芒格对巴菲特投资哲学的影响——从"便宜货"转向"优质公司"

### 2. 可口可乐投资（1988年开始）
- **决策**: 巴菲特开始买入可口可乐股票，价格约每股11美元
- **芒格角色**: 强烈推荐，认为可口可乐拥有强大品牌、忠诚消费者、高利润率
- **逻辑**: 
  - 全球品牌认知
  - 简单、可预测的生意
  - 强大的分销网络
- **结果**: 成为伯克希尔历史上最成功的投资之一

### 3. 比亚迪投资（2008年）
- **决策**: 伯克希尔投资2.3亿美元买入比亚迪股份
- **芒格角色**: 强烈推荐，称王传福是"爱迪生和杰克·韦尔奇的混合体"
- **逻辑**: 
  - 技术护城河（电池技术）
  - 优秀的管理层
  - 新能源车的长期趋势
- **结果**: 到2023年，这笔投资价值超过70亿美元

### 4. Daily Journal技术业务转型
- **决策**: 将Daily Journal从衰退的报纸业务转型为法院软件业务（Journal Technologies）
- **逻辑**: 
  - 报纸业务不可逆转地衰退
  - 法院自动化是巨大市场
  - 缓慢但确定的长期趋势
- **芒格角色**: 主导转型决策
- **现状**: "漫长而缓慢的奋斗"，但是未来所在

## 重大决策与转折点

### 1. 从律师转向投资（1960年代）
- **背景**: 芒格原为律师，年收入丰厚但"天花板可见"
- **决策**: 逐步减少法律业务，全职从事投资
- **逻辑**: 
  - 发现投资的复合回报潜力
  - 与巴菲特的合作提供了规模优势
- **结果**: 改变了人生轨迹

### 2. 创建伯克希尔·哈撒韦（1965年）
- **决策**: 与巴菲特联手，通过纺织公司伯克希尔作为投资平台
- **逻辑**: 需要一个公开交易的载体来进行大规模投资
- **结果**: 创造了投资史上最优秀的记录（年均20.3%复合收益率）

### 3. 房地产投资（1960年代）
- **决策**: 参与"自治社区工程"等房地产开发项目
- **结果**: 赚到人生第一个百万美元
- **意义**: 证明了芒格在非传统投资领域的能力

## 失败与误判案例

### 1. 科技股回避
- **决策**: 长期回避科技/软件公司股票
- **理由**: "软件和高科技动态超出我们的专业领域"
- **结果**: 错过了微软、苹果（早期）、谷歌等巨大机会
- **反思**: 芒格承认这是"能力圈"的自我约束，但也可能是一种局限

### 2. 所罗门兄弟公司危机（1991年）
- **背景**: 所罗门兄弟公司违规投标国债，面临倒闭
- **芒格角色**: 作为董事参与危机处理
- **决策**: 支持巴菲特接管并挽救公司
- **结果**: 成功避免倒闭，但事件揭示了华尔街文化的腐败
- **芒格评论**: 用此案例说明"激励机制"和"心理误判"的后果

### 3. 对加密货币的态度
- **决策**: 极端负面，称比特币为"老鼠药"、"欺诈"
- **结果**: 到目前为止（2023年），比特币价格大幅上涨，芒格的判断被市场打脸
- **分析**: 可能体现了芒格在快速变化技术领域的认知局限

## 决策风格特征

### 1. 极度理性
- 基于事实和逻辑，而非情绪
- 愿意改变想法（"我每年不摧毁一个我爱的想法，那是浪费的一年"）

### 2. 逆向思考
- 先研究"如何失败"，再研究"如何成功"
- 例: 研究"哪些公司会衰败"来决定"哪些公司会成功"

### 3. 长期主义
- 决策时考虑10-20年的时间跨度
- "我们喜欢持有那些我们永远不会卖出的股票"

### 4. 集中投资
- 反对过度分散
- "少即是多"——集中持有少数优质公司

### 5. 安全边际
- 永远保留40%的安全边际（从父亲处继承的"破产律师思维"）

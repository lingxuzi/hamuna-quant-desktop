# Agent 6: 人物时间线调研

## 完整时间线

### 早期生活与教育（1924-1948）
- **1924年1月1日**: 出生于美国内布拉斯加州奥马哈市
- **1930年代**: 大萧条时期，形成"反脆弱思维"和"安全边际"意识
- **1941年（17岁）**: 进入密歇根大学学习数学
- **1942年**: 珍珠港事件后参军，在新墨西哥大学、加州理工大学研究气象学
- **1944-1946年**: 服役于军队，担任气象学家（阿拉斯加），未实际参战
- **1948年**: 以优异成绩毕业于哈佛大学法学院（未经本科学位直接录取）
- **1948年后**: 进入加州法院当律师，并开始证券投资

### 职业生涯早期（1948-1978）
- **1950年代**: 从事法律工作，同时投资于证券和房地产
- **1959年**: 在一场葬礼上与沃伦·巴菲特相识，开启60年合作
- **1960年代**: 参与房地产开发项目"自治社区工程"，赚到第一个百万美元
- **1965年**: 与巴菲特联手，通过伯克希尔·哈撒韦公司作为投资平台
- **1960年代末**: 逐步从法律业务转型为全职投资
- **1972年**: 说服巴菲特以2500万美元收购See's Candies（关键转折点）
- **1978年**: 正式担任伯克希尔·哈撒韦公司副主席

### 黄金时期（1978-2023）
- **1984-2011年**: 担任Wesco Financial董事长兼首席执行官
- **1988年**: 推动巴菲特投资可口可乐
- **1995年**: 在哈佛大学发表《人类误判心理学》演讲（后扩展为25个偏差）
- **2005年**: 《穷查理宝典》首版出版
- **2008年**: 推荐比亚迪投资
- **2010年代**: Daily Journal业务转型为法院软件（Journal Technologies）
- **2020年**: 以16亿美元财富位居福布斯全球亿万富豪榜第1335位
- **2022年5月**: 据路透社报道，获连任伯克希尔副主席
- **2023年2月**: 最后一次公开亮相（Daily Journal年会）
- **2023年10月29日**: 进行播客首秀
- **2023年11月28日**: 在加州一家医院安详去世，享年99岁（距100岁生日仅一个月）

## 思想转折点

### 1. 从"便宜货"到"优质公司"（1972年）
- **事件**: See's Candies收购
- **转变**: 从格雷厄姆式"便宜就好"到芒格式"优质更重要"
- **影响**: 重塑了伯克希尔的投资哲学

### 2. 多元思维模型的系统化（1990年代）
- **事件**: 《人类误判心理学》演讲 + 多次演讲中阐述"latticework"
- **转变**: 从"价值投资"到"多学科思维"
- **影响**: 创造了芒格独特的认知框架

### 3. 技术业务的接受（2010年代）
- **事件**: Daily Journal转型做法院软件
- **转变**: 从"避开科技"到"拥抱特定科技"（缓慢、可预测的科技）
- **影响**: 展示了芒格的适应能力

## 最近12个月动态（2022-2023）

### 2022年
- 继续担任Daily Journal和伯克希尔副主席
- 多次表达对中国的乐观态度
- 继续在伯克希尔年会和Daily Journal年会发言

### 2023年
- **2月**: Daily Journal年会（最后一次公开亮相），谈AI、否认倾向、董事会治理
- **10月**: 播客首秀（99岁首次做播客）
- **11月28日**: 去世

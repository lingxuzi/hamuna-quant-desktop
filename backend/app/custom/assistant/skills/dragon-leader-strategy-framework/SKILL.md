# 龙头战法交易框架



## 框架概览



龙头战法是 A 股超短线核心战法，本质是在市场情绪上升期参与最强板块的最强个股，在情绪下降期空仓休息，反复循环。核心公式：



**龙头战法 = 情绪周期判断 × 龙头识别 × 时机选择 × 纪律执行**



五步回答工作流：情绪周期判断 → 龙头识别 → 上车时机 → 持仓管理 → 退出信号



---



## 一、情绪周期判断



情绪周期是龙头战法的地基。不看周期谈龙头，是刻舟求剑。



### 周期四阶段



| 阶段 | 市场特征 | 操作策略 |

|------|---------|---------|

| **冰点期** | 涨停数持续下降，跌停家数上升甚至超过涨停；连板高度压制至3板以下；昨日涨停无溢价甚至闷杀；无主流热点，热点一日游 | **空仓等待**，管住手，不怕踏空 |

| **启动期（异动期）** | 跌停/闷杀现象消失；涨停炸板减少；新题材异动；某股打破3-4板空间压制，逆势创近期新高 | **小仓试错**，做首板一进二，追涨空间突破票 |

| **发酵期→高潮期** | 连板股数量增多；板块赚钱效应扩散；龙头加速，跟风批量涨停 | **重仓出击**，这是龙头选手最关键阶段，聚焦最主流热点龙头 |

| **退潮期** | 龙头炸板/跌停；中位股/跟风先崩；连板骤减；放量滞涨；跌停家数激增 | **逐步减仓→空仓**，从积极进攻过渡到防守 |



### 情绪量化指标



- **涨跌停比**：连续>3 预示高潮，<1 进入冰点

- **连板高度**：最高板骤降 = 退潮信号

- **炸板率**：升高 = 情绪分歧加大

- **龙头溢价率**：龙头 vs 板块指数超额收益



### 周期核心心法



> 情绪为王，模式为辅。启动→发酵→高潮→退潮决定买卖点，而非固定模式。

> 预判次日情绪延续性：复盘涨停股属性 + 政策消息 + 市场量能 → 推测资金流向。

## 二、龙头识别（三维度）



### 维度一：情绪龙头



- **定义**：市场情绪的风向标，它的涨跌直接影响全局赚钱效应

- **特征**：

  - 率先启动，逆势走强（在情绪拐点前就敢拉2-3板）

  - 跌时抗跌，涨时领涨

  - 断板时引发全场情绪退潮

- **识别要点**：看它断板那天，市场是否随之崩盘——如果是，它就是情绪龙头



### 维度二：题材龙头



- **定义**：某一板块/题材中最先启动、涨幅最大、带动性最强的票

- **特征**：

  - **带动性**：能带动同题材、同名字、甚至"玄学"属性的批量涨停

  - **封板速度**：第一时间涨停，封板速度快，封单量大

  - **板块地位**：板块最高连板，先于板块涨停，带动跟风上涨

- **三种龙头类型**：



| 类型 | 产生条件 | 典型涨幅 |

|------|---------|---------|

| **总龙头（妖股）** | 个股重大利好 + 周期共振 | 短期数倍，10-20板 |

| **周期龙头** | 冰点后指数/情绪/题材共振回暖日的最高板 | 视周期强度 |

| **板块龙头** | 多主线行情中，每个持续热点板块的领涨票 | 板块内最强 |



> 大题材/重大利好 → 总龙头；一般性题材 → 板块龙头（最多周期龙头）

> 新周期龙头不会在老题材里诞生，除非利好不断加持



### 维度三：连板龙头



- **核心规律**：龙头必须从首板开始，逐板验证



| 板数 | 阶段 | 要点 |

|------|------|------|

| **首板** | 海选期 | 从新题材/主线题材中找；炒新不炒旧 |

| **二板** | 龙头种子 | 确认题材持续性；打板进入，不涨停就套利走人 |

| **三板** | 龙头确认 | 梯队完整321则龙头概率大增；2板即可定龙头（赵老哥） |

| **四板** | 龙头捂股 | 初具龙头气质；此前一致加速则需分歧换手；已有则捂，没有则不追 |

| **五板** | 板块龙天花板 | 能晋级则成空间破局龙，失败则回归 |

| **六板+** | 情绪博弈 | 纯情绪驱动，心跳加速，需对题材/政策/环境/情绪清晰判断 |



### 龙头识别的黄金标准



1. **爆量换手检验**：分歧日实际换手率≥30%，洗出获利盘，吸引接力资金

2. **未爆量分歧的龙头**：一致加速→获利盘过重→买盘枯竭→天地大面→情绪退潮

3. **市场合力**：真龙头是各路资金合力推进，非单一庄家控盘

## 三、上车时机



### 时机一：首板/二板试错（启动期）



- **适用**：情绪冰点转启动，新题材异动

- **方法**：

  - 一板后放量关注，二板强势封板可进场

  - 二板不能封板则次日不上攻就走人

  - 高开且快速封板 = 强势信号



### 时机二：分歧转一致（核心买点）



**这是龙头战法最核心的买点。** "买在分歧，卖在一致。"



**分歧转一致的本质**：筹码通过分歧完成转移（换手），多空从分歧到一致看涨。



**三次分歧转一致买点**：



| 次数 | 出现位置 | 龙头进阶 | 后续空间 |

|------|---------|---------|---------|

| **第一次** | 3-5板 | 前排→板块龙头 | 加速2-3天 |

| **第二次** | 6-9板 | 板块龙→空间龙 | 加速2-3天 |

| **第三次** | 9-11板 | 空间龙→周期龙 | 加速2-3天后基本完成使命 |



> **第三次分歧转一致成功率最低，基本到顶。**



**判断分歧转一致的三个层次**：



1. **量能**：三板放量 > 前两板，分歧日爆量换手

2. **分时**：早盘分歧（低开/冲高回落）→ 盘中充分换手 → 午后/尾盘回封涨停

   - 分时V反转+W型反转拉升涨停，股价拉上均价线 = 买点

3. **隔日验证**：

   - 弱转强成功且强势 → 持仓不动，让利润奔跑

   - 弱转强扭捏无量 → 相对高位卖出

   - 弱转强失败 → 立刻高开离场，等再次分歧转一致



**分时图买法 vs 日线买法**：

- 分时图：开盘多空分歧→空方砸盘→多方承接→V/W反转→拉上均价线买入

- 日线：放量烂板（仍封涨停）→ 次日带量高开（该弱不弱则为强）→ 竞价介入或封板确认后打板



### 时机三：龙回头（龙头回调后二次上车）



- **条件**：龙头第一次大分歧后回调，5日均线支撑

- **买点**：回调至关键支撑位，出现分歧转一致信号

- **注意**：仅限第一次回调有效，二次回调风险极大

## 四、持仓管理



### 持仓原则



1. **有龙做龙**：持有龙头不做跟风

2. **捂龙待涨**：确认龙头后，只要趋势不破就持有

3. **分仓管理**：试错期分仓（3-5板试错），确认后集中

4. **五日线为界**：5日线之上持有，破5日线减仓



### 情绪与持仓的映射



| 情绪阶段 | 仓位 | 操作风格 |

|---------|------|---------|

| 冰点期 | 0% | 空仓 |

| 启动期 | 10-30% | 试错 |

| 发酵期 | 50-70% | 加仓 |

| 高潮期 | 70-100% | 捂仓 |

| 退潮初期 | 30-50% | 减仓 |

| 退潮确认 | 0% | 清仓 |

## 五、退出信号（龙头退潮识别）



龙头战法最重要的不是攻击力，而是防守——退潮时你还能剩多少。



### 核心退出信号（按重要性排序）



1. **龙头断板/跌停**：最直接的退潮信号，龙头死了全场陪葬

2. **中位股/跟风先崩**：中位股出现严重负反馈（天地板/跌停），负反馈会往高位传导

3. **放量滞涨**：放出巨量但股价不涨，长上影线/阴线 = 主力出货

4. **一致加速后的放量分歧**：连续一致加速后突然放量分歧且无法回封 = 头部信号

5. **板块退潮**：跟风股纷纷下跌，龙头独木难支，补跌在即

6. **MACD顶背离**：股价新高但MACD不新高，上涨动力衰竭

7. **破20日线**：有效跌破20日线，短期趋势改变



### 退潮期操作铁律



> **退潮期最好的操作 = 空仓。** 不要怕踏空，只怕套牢。

> 从积极进取 → 防守反击 → 谨慎防守，逐步减仓。

> 等待下一个冰点转折点和新题材启动。



### 卖出心法



- "买入分歧，卖出一致"——连续一致加速时逐步兑现

- 龙头死于跌停，妖股死于加速

- 放量大阴线 = 情绪分歧，果断离场

- 第三次分歧转一致后基本见顶

## 六、风险警示与诚实边界



### 本框架的局限



1. **历史规律不保证未来**：情绪周期和龙头规律基于统计概率，非确定性规律

2. **市场环境变化**：注册制、量化资金、监管政策变化可能改变龙头战法的有效性

3. **黑天鹅事件**：突发利空可打断任何周期规律

4. **个人执行偏差**：知行合一是最大难点，框架不能替代纪律



### 高危陷阱



- **高位博傻**：情绪全面回暖后追高龙头 = 接盘战法

- **退潮期抄底**：龙头回调不等于龙回头，退潮期无底

- **一致加速追涨**：获利盘过重+买盘枯竭=天地大面

- **忽视周期**：不看情绪周期直接上龙头 = 盲人骑瞎马



### 适用前提



- A股T+1环境，10%涨跌幅限制（科创板/创业板20%需调整参数）

- 市场有活跃游资参与，流动性充足

- 交易者具备快速盯盘能力（超短线需实时决策）

## 回答工作流



当用户提出龙头战法相关问题时，按以下流程结构化回答：



```

1. 情绪周期判断 → 当前处于哪个阶段？量化指标怎么说？

2. 龙头识别 → 三个维度（情绪/题材/连板）分别指向谁？

3. 上车时机 → 是否出现分歧转一致？是第几次？隔日弱转强如何？

4. 持仓管理 → 仓位多少？5日线支撑？情绪阶段匹配？

5. 退出信号 → 有无退潮征兆？中位股/跟风表现？放量滞涨？

```



每个环节给出明确判断，不确定时标注"需观察"而非猜测。

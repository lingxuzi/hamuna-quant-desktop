# 筹码分析智能体 (Chip Analysis Framework)

## 框架概览

筹码分析（Chip Analysis），又称筹码分布理论或成本分析，是通过统计不同价格区间内的持仓成本分布，来研判主力资金动向和市场情绪的技术分析方法。

核心逻辑：**筹码是主力与散户交换的载体**。通过观察筹码的分布、移动和集中度变化，可以识别主力处于吸筹、洗盘、拉升还是出货阶段，从而做出更精准的交易决策。

### 适用场景
- 中短线交易（持仓周期几天到几周）
- 研判主力行为（庄家/机构动向）
- 识别支撑位、压力位
- 判断趋势延续性或反转

### 局限性（诚实边界）
1. **需要Level-2数据**：精确的筹码分布需要逐笔成交数据，普通行情软件可能有误差
2. **滞后性**：筹码分布基于历史成交，无法预测突发消息或政策变化
3. **主力伪装**：主力可能通过对倒、分仓等手段制造假筹码形态
4. **适用于流动性好的个股**：小盘股/庄股可能被高度控盘，筹码分析失效
5. **信息截止**：本框架基于公开技术理论，不包含实时市场数据

---

## 方法论对比

| 维度 | 筹码分布法 | 传统技术指标（MACD/KDJ等） |
|------|------------|---------------------------|
| **分析对象** | 持仓成本结构 | 价格/成交量统计数据 |
| **核心优势** | 直接观察主力成本区和筹码转移 | 提供量化买卖信号 |
| **滞后性** | 中等（基于成交筹码） | 高（基于历史价格计算） |
| **适用场景** | 识别主力意图、支撑压力位 | 趋势跟踪、超买超卖判断 |
| **局限性** | 需要一定换手率才能形成有效筹码峰 | 震荡市中频繁发出假信号 |

**最佳实践**：筹码分析 + 量价关系 + 趋势判断，三重验证提高胜率。

## 回答工作流（Agentic Protocol）

当用户提出筹码分析相关问题时，按以下流程执行：

### 第一步：筹码分布分析
1. 观察筹码峰的位置和形态（单峰/多峰/发散）
2. 判断筹码集中程度（集中度数值）
3. 识别获利盘/套牢盘比例

### 第二步：主力行为判断
根据筹码形态和股价位置，判断主力处于哪个阶段：
- 吸筹阶段：低位单峰密集，成交量温和放大
- 洗盘阶段：底部筹码锁定，股价剧烈震荡但关键支撑不破
- 拉升阶段：股价突破筹码峰，底部筹码仍锁定
- 出货阶段：高位筹码分散，底部筹码快速消失

### 第三步：买卖时机确认
结合以下信号给出操作建议：
- **买入信号**：低位单峰密集 + 放量突破 + 上方无套牢盘
- **持有信号**：上涨多峰 + 底部筹码锁定 + 新峰增大原峰存在
- **卖出信号**：高位筹码分散 + 底部筹码消失 + 放量滞涨

## 核心知识体系

### 一、筹码分布原理

#### 1.1 基本概念
- **筹码分布图**：在K线图右侧，由水平柱状条构成。每根柱状条长度表示该价位持仓量占总流通盘的百分比。
- **获利盘**（红色筹码）：持股成本低于当前股价的筹码
- **套牢盘**（蓝色筹码）：持股成本高于当前股价的筹码
- **平均成本线**（黑色/黄色线）：所有持仓者的平均持仓成本

#### 1.2 筹码流动的计算逻辑
每日筹码分布更新公式（简化版）：
```
当日筹码 = 前日剩余筹码 × (1 - 换手率) + 当日新成交筹码
```

**关键原理**：
- 换手率10% → 昨天90%的筹码"留存"，10%被新买入者替换
- 新成交筹码按当日价格分布（如分布在最高价与最低价之间）
- 筹码是**动态转移**的：从散户向主力转移（吸筹），或从主力向散户转移（出货）

#### 1.3 筹码集中度指标
用于衡量筹码在特定价格区间的集中程度。

**通达信公式示例**：
```pascal
筹码集中度90 = (COST(95) - COST(5)) / (COST(95) + COST(5)) * 100
```
- `COST(N)`：表示N%的筹码成本低于此价格
- 集中度数值**越小**，筹码越集中
- 一般标准：
  - <10：高度集中（主力控盘）
  - 10-20：较集中
  - >30：分散

### 二、筹码峰解读

筹码峰是筹码分布图中形成的"山峰"状密集区，代表大量筹码集中在某一价格区间。

#### 2.1 单峰密集

**定义**：某一价格区间内筹码高度集中，形成单一峰值。

**分类与操作策略**：

| 类型 | 特征 | 操作策略 |
|------|------|----------|
| **低位单峰密集** | 股价经过长时间整理，在低位形成单峰 | **买入信号**：股价放量突破单峰时介入 |
| **上涨中继单峰** | 拉升途中形成的新的单峰密集 | **持有/加仓**：每一个密集峰都是强支撑 |
| **高位单峰密集** | 股价大幅上涨后在高位形成单峰 | **谨慎**：可能是主力出货区，准备减仓 |

**关键要点**：
- 单峰密集程度越大 → 筹码换手越充分 → 后续上攻/下跌力度越大
- 股价突破单峰密集后，通常会有**缩量回调**，回调至筹码峰附近获得支撑

#### 2.2 多峰密集

**下跌多峰**：
- 形成次序：上密集峰 → 下密集峰
- 上密集峰是**套牢峰**，下密集峰是**吸筹峰**
- **操作**：上峰未消失前，不宜建仓（上方套牢盘压力大）

**上涨多峰**：
- 形成次序：下密集峰 → 上密集峰
- 上密集峰的筹码来自下密集峰的部分移位
- **操作**：新峰增大、原峰仍存在 → 继续持股；原峰迅速减少 → 考虑出局

#### 2.3 双峰密集

由上下两个密集峰构成，对股价运行有较强的支撑力和阻力。
- 下峰：强支撑位
- 上峰：强阻力位
- **突破上峰** → 新一轮上涨开始
- **跌破下峰** → 新一轮下跌开始

---

### 三、获利盘/套牢盘分析

#### 3.1 获利盘分析

**获利比例** = 获利盘筹码量 / 总流通筹码

**操作含义**：
- 获利比例 > 80%：大部分筹码处于盈利状态，抛压可能增大
- 获利比例 < 20%：大部分筹码被套，抛压小，容易反弹

**获利不抛的筹码是主力的筹码**：
- 获利30%以下，主力通常不会出货
- 如果股价上涨但获利盘没有大幅减少 → 主力锁仓

#### 3.2 套牢盘分析

**套牢比例** = 套牢盘筹码量 / 总流通筹码

**操作含义**：
- 套牢比例高 → 上方抛压重 → 股价上涨阻力大
- 套牢比例低 → 上方压力小 → 容易突破

**解套不卖的筹码是主力的筹码**：
- 如果股价回升至套牢区，但套牢筹码没有明显减少 → 主力在建仓

#### 3.3 筹码乖离率

**定义**：获利盘与平均成本线的偏离程度。

**操作含义**：
- 乖离率越小 → 获利的人越少 → 抛压小
- 乖离率越大 → 获利的人越多 → 抛压大

---

### 四、筹码转移识别

#### 4.1 筹码移动方向

| 移动方向 | 含义 | 操作建议 |
|---------|------|----------|
| **向上移动** | 筹码从低位向高位转移（可能是主力拉升或散户追高） | 结合成交量判断：缩量上涨→主力锁仓；放量上涨→可能出货 |
| **向下移动** | 筹码从高位向低位转移（可能是主力出货或洗盘） | 结合底部筹码：底部筹码锁定→洗盘；底部筹码消失→出货 |

#### 4.2 筹码峰的演变

**峰位转移**：
- 筹码峰从低位向高位转移 → 主力在派发
- 筹码峰从高位向低位转移 → 主力在吸筹

**峰值变化**：
- 峰值增大 → 资金入场增多，可能推动股价上涨
- 峰值减小 → 资金离场，股价可能调整

#### 4.3 筹码发散与集中

- **集中 → 发散**：筹码从密集区向四周分散，可能是主力出货或行情进入无序状态
- **发散 → 集中**：筹码从分散状态重新聚集到某一价格区，可能是主力重新吸筹

### 五、主力行为研判

主力操作一般分为四个阶段：**吸筹 → 洗盘 → 拉升 → 出货**

#### 5.1 吸筹阶段（Accumulation）

**筹码特征**：
- 股价低位横盘震荡，形成**低位单峰密集**
- 成交量呈现"红肥绿瘦"（上涨放量、下跌缩量）
- 筹码集中度逐渐提高（COST指标数值减小）

**K线特征**：
- 慢牛走势：股价缓慢上扬，抗跌性强
- 牛长熊短：上涨时间长、下跌时间短且幅度小
- 经常出现十字星、T字线等小阴小阳线

**盘口特征**：
- 分时图频繁出现"钓鱼线"（突然打压后快速拉回）
- 买盘挂单密集，卖盘挂单稀疏
- 成交量温和放大但股价涨幅不大（压价吸筹）

**如何判断吸筹尾声**：
1. 很小的量就能拉出大阳线或涨停
2. K线走势独立，不随大盘波动
3. 遇到利空不跌反涨
4. 筹码低位高度集中（集中度<10）

#### 5.2 洗盘阶段（Washing）

**目的**：把低成本的筹码震荡出来，抬高市场平均持仓成本，减轻后续拉升的抛压。

**筹码特征**：
- **底部筹码峰未明显减少**（主力未抛售）
- 筹码在短期波动区间重新分布
- 获利盘比例下降后快速回升（主力护盘）

**K线特征**：
- 剧烈震荡但关键支撑位不破（如20日/30日均线）
- 经常出现长上影线或长下影线
- 缩量下跌、放量反弹（量价背离）

**洗盘与出货的关键区别**：

| 维度 | 洗盘 | 出货 |
|------|------|------|
| **筹码分布** | 底部筹码锁定 | 底部筹码快速消失 |
| **成交量** | 下跌缩量、反弹放量 | 下跌放量、反弹缩量 |
| **股价位置** | 低位或涨幅<50% | 高位或涨幅>80% |
| **分时走势** | 上蹿下跳、振幅大 | 平稳或缓慢阴跌 |
| **持续时间** | 短（1-3周） | 长（1个月以上） |

**常见洗盘形态**：
1. **挖坑洗盘**：故意压低股价制造破位假象，随后快速拉回
2. **假阴线洗盘**：高开后压低价格，看似收跌实际未跌
3. **长上影线洗盘**：多次测试上方压力，制造"压力重"假象

#### 5.3 拉升阶段（Pulling）

**筹码特征**：
- 股价突破低位筹码峰，上方套牢盘被消化
- **底部筹码仍锁定**（获利盘不抛）
- 上涨时缩量（主力控盘高，无需大量对倒）

**K线特征**：
- 阳多阴少，股价沿5日/10日均线攀升
- 经常出现"空中加油"形态（短暂整理后继续上涨）
- 成交量呈现"梯量"形态（逐步放大但不过分）

**操作策略**：
- **持股为主**：每一次回调都是加仓机会
- 关注新形成的密集峰：每一个新峰都是强支撑
- 止损位：跌破20日均线或筹码峰下沿

#### 5.4 出货阶段（Distribution）

**筹码特征**：
- **高位筹码分散**，形成多个小峰
- **底部筹码峰快速消失**（主力在派发）
- 筹码从集中变为发散

**K线特征**：
- 放量滞涨：成交量放大但股价不涨
- 经常出现长上影线、墓碑线
- 股价跌破关键支撑位后反弹无力

**出货的三种典型形态**：
1. **拉高出货**：小单拉高、大单打下，制造买盘活跃假象
2. **打低出货**：直接大幅低开或快速打压，毫不掩饰地抛售
3. **锯齿形出货**：在高位构建平台，培养市场"突破"心理，不知不觉中派发

**出货的明确信号**：
- 底部筹码消失 > 50%
- 高位形成多个分散峰
- 放量滞涨或放量下跌
- 利好频出但股价不涨

**操作策略**：
- **果断离场**：不要幻想"再涨一点"
- 止损位：跌破高位筹码峰下沿或20日均线
- 避免"抄底"：出货后的股票可能长期阴跌

### 六、实战选股

#### 6.1 选股条件（筹码角度）

**理想买入形态**：
1. **低位单峰密集** + 股价放量突破
2. **上峰消失** + 低位形成新单峰密集
3. **上涨多峰** + 新峰增大、原峰仍存在
4. **筹码集中度** < 15（高度集中）
5. **获利比例** 30%-70%（既有上涨空间，又有一定持有信心）

**需要回避的形态**：
1. **高位单峰密集** + 成交量放大（可能是出货）
2. **下跌多峰** + 上峰未消失（上方套牢盘重）
3. **筹码高度分散** + 无明确密集峰（主力控盘度低）
4. **底部筹码快速消失** + 高位筹码增加（主力在出货）

#### 6.2 结合其他指标的验证

**量价关系验证**：
- 突破筹码峰时必须放量（验证突破有效性）
- 回调时必须缩量（验证主力锁仓）

**趋势验证**：
- 均线系统：最好呈现多头排列（5日>10日>20日>60日）
- 趋势线：股价在上升趋势线上方运行

**市场环境验证**：
- 大盘趋势：牛市中筹码突破成功率更高
- 板块效应：同板块多只股票同时出现筹码集中 → 板块行情可能启动

#### 6.3 风险控制

**止损设置**：
- 买入后跌破筹码峰下沿 → 止损
- 买入后底部筹码快速消失 → 止损
- 固定止损：单笔亏损不超过总资金的3%-5%

**仓位管理**：
- 初期建仓：30%-50%仓位
- 突破确认后：加仓至70%-80%
- 高位滞涨：减仓至30%以下

## 典型形态速查表

### 九大经典筹码形态

| 序号 | 形态名称 | 特征 | 操作建议 |
|------|----------|------|----------|
| 1 | **放量突破低位单峰密集** | 长时间整理后，低位形成单峰，股价放量突破 | **买入**（一轮上升行情开始） |
| 2 | **上峰消失** | 下跌行情中，上密集峰被消耗，低位形成新单峰 | **买入**（见底企稳信号） |
| 3 | **上涨多峰密集续涨** | 拉升途中形成多个密集峰，原峰仍存在 | **持有/加仓**（行情持续） |
| 4 | **向上突破高位单峰密集** | 股价再次突破高位峰密集，创出新高 | **谨慎买入**（新一轮升势，但风险增大） |
| 5 | **超跌V型反转至峰密集** | 股价快速跌穿原单峰密集，原峰仍完好 | **观望**（等待反弹至原峰附近时减仓） |
| 6 | **洗盘回归单峰密集** | 洗盘结束后重新形成单峰密集 | **买入**（新一轮行情即将开始） |
| 7 | **跌破高位单峰密集** | 股价跌破高位单峰密集 | **卖出**（下跌开始） |
| 8 | **回调峰密集获强支撑** | 股价回调至筹码峰附近获得支撑 | **买入/持有**（继续看涨） |
| 9 | **洗盘后再度密集** | 洗盘结束后重新形成筹码密集 | **买入**（新一轮行情启动） |

当用户提出具体股票或市场问题时，使用以下模板回答：

### 模板1：筹码分布分析（详细版）
```
## 筹码分布分析

### 当前筹码结构
- 筹码峰位置：[具体价格区间]
- 筹码集中度：[数值]（集中/分散）
- 获利盘/套牢盘比例：[数值]%
- 平均成本线位置：[价格]

### 主力行为判断
- 当前阶段：[吸筹/洗盘/拉升/出货]
- 关键证据：[列出2-3个筹码特征]
- 主力成本区：[价格区间]
- 筹码锁定情况：[底部筹码是否锁定/消失比例]

### 操作建议
- 买入/卖出/持有：[明确建议]
- 关键位置：支撑位 [价格] / 压力位 [价格]
- 止损位：[价格]
- 风险提示：[列出1-2个风险点，如假突破、主力伪装等]

### 验证建议
- 结合量价关系：[是否放量突破/缩量回调]
- 结合趋势：[是否在上升趋势中]
- 结合基本面：[是否有重大利好/利空]
```

## 质量标准

### 好的回答应该具备：
1. **明确判断**：给出清晰的买入/卖出/持有建议，不模棱两可
2. **证据充分**：列出2-3个筹码特征作为判断依据（如"底部筹码锁定"、"高位分散"等）
3. **风险提示**：明确指出可能的假突破或主力伪装，说明信心指数
4. **关键位置**：给出具体的支撑位和压力位价格（如有具体股票）
5. **可操作性**：提供明确的止损位和目标位

### 避免的问题：
1. **过度自信**：不使用"一定"、"肯定"等绝对化语言，改用"概率较大"、"可能性高"
2. **忽略局限性**：每次分析都应提及筹码分析的滞后性和可能误差
3. **孤立分析**：提醒用户结合量价关系、趋势、基本面综合判断
4. **缺乏量化**：尽量给出具体数值（如集中度、获利比例），而非模糊描述

### 诚实边界检查清单
分析时必须提及的局限性：
- [ ] 筹码分布基于历史数据，存在滞后性
- [ ] 需要足够换手率才能形成有效筹码峰（新股/长期停牌股不适用）
- [ ] 主力可能通过对倒、分仓伪装筹码形态
- [ ] 突发消息/政策变化可能导致筹码分析失效
- [ ] 小盘股/庄股可能被高度控盘，筹码分析参考价值降低

# 估值分析智能体

## 功能介绍

本Skill是一套完整的企业估值分析系统，提供了从估值方法选择、参数确定、计算执行到结果解读的全链路分析框架。基于主流估值理论（达摩达兰估值框架、格雷厄姆价值投资理论、彼得林奇成长估值体系），结合A股/港股/美股市场实践经验，帮助投资者系统性地评估企业内在价值与市场价格之间的关系。 估值不是精确的科学，而是在合理边界内寻找"模糊的正确"巴菲特。
